# 扩围后的独立提案与主线审查

记录时间：2026-10-22 UTC。仅查原始来源、提出设计；本轮未训练、未下载图像/模型、未启动后台任务。没有读取旧封存数组，也没有改写旧阴性结论。保持当前模型设置；没有可验证的实际 Fast 后端回执。

## 结论

**优先主线，有条件进入预注册开发实验。** 主线应准确称为“固定预训练 ViT、同 LoRA 参数量时，插入位置是否改变 RandAugment 对干净任务泛化的收益”。它可以是有意义的有限经验问题；目前没有依据称为新机制或新算法。早层适合输入变化、PEFT 需要适合的增强，这两条动机已有直接先例。

**只保留一个实质不同备选：CutMix 后再执行空间增强时，过期的面积 soft target 是否会造成可测的训练损失；同步运输来源图能否恢复这部分损失。** 与 OA-CutMix 高度接近，但其已读正文没有给出下面“相同增强图像、不同来源记账”的顺序控制。允许它作为低优先级、重叠风险明确的经验备选；不建议与主线同时开训，也不宣称首次发现标签不匹配。标准先 RA 后 CutMix 已避开这里研究的额外来源面积问题，因此不能人为制造一个坏流程，再把修复包装成普遍算法收益。

## 主线：最近邻与剩余差异

### 对更新后的具体主方案的判断

主线已明确为前 3 个 block 的 Q/V 各 r=4、后 3 个 block 的 Q/V 各 r=4、全 12 个 block 的 Q/V 各 r=1；弱基线与标准 RA(N=2,M=9)。这个修订合理。不能把“基础权重被冻结”误说成“早层表示被冻结”：早层 attention 中的 LoRA 仍能改变早层表示；主问题是**可学习扰动的位置和秩分配**。

若隐维为 d，Q/V 都为 d×d，单 block 的 LoRA 参数为 4dr，以上三种布局的 LoRA 参数均为 48d；共享分类头另计。必须从实际 `requires_grad` 清单核验，而不是只用公式推断。QKV 融合实现要确认只更新 Q/V；bias、LayerNorm、位置编码、patch embedding、head 和 dropout 的状态应在各格一致。全层 r=1 与局部 r=4的函数类和梯度尺度不相同，适合作为分布式预算参照，不能据其结果独立归因于层位置。**主检验应是前 3 层 r4 对后 3 层 r4的交互**。

令 E 是同一个干净开发集的错误率，定义 G_p=E(p,weak)−E(p,RA)，主量 I=G_early−G_late。预先写清方向和实用阈值；例如预测 I≥0.5 个百分点是一种工程门，不能称为统计显著性标准。必须报告四个绝对错误率及每个种子的 I；若只有 early 本来更强、两种位置的 RA 收益相同，则该假设失败。若两者都被 RA 伤害且 early 伤害较小，只能说交互成立，不能说“早层解锁了 RA 收益”。

可识别的是该预训练权重、任务、优化配方和训练期限下的算法处理交互。它不能单独证明“视觉低层不变性是因果机制”，也不能推广到所有 LoRA、所有增强或所有预训练模型。

### 主线必须处理的混淆

1. **优化而非表示瓶颈。** 同一学习率不等于公平优化；允许每种布局在同一个很小、预先固定的 LR 网格中用同一开发预算选择，再锁定。不能只对失败格多调参。若资源不足以调参，明确研究的是共同配方下的交互。早/后 r4 使用相同 LoRA scaling；全层 r1 的 scaling/初始化单独说明，不能让它主导位置结论。
2. **参数量不等于训练计算。** 早层更新要反传更多冻结 block。主比较宜固定源图、数据次序、增强次数、batch、更新数和评估次数，分别报告实际时间/内存；不要称为 FLOPs 或墙钟完全相等。若采用相同墙钟，更新数不同就变成另一种资源问题。
3. **真正训练表示。** 保存各布局实际活跃的梯度、非零 LoRA 更新，以及固定开发图片的中间/最终特征变化。LoRA 是真实表示训练，即使 base weights 冻结；不能用旧冻结特征头代替。本轮父线程的合成 MPS 计时仅是兼容/资源证据，不能作为科学结果。
4. **数据和独立单位。** 配对种子控制初始化、样本顺序和增强 RNG。训练重复的单位是完整 run；增强视图、batch、block 都不是独立重复。图像 bootstrap 仅反映固定模型在该数据池上的不确定性，不能代替种子重复。若数据含同物体/近重复，应按身份或可核实的重复组分割。预训练重叠未知时如实限制结论。
5. **近邻差异需要结果支持。** 一个任务的均值小差不能支撑一般 mismatch。至少要有一致的配对交互、绝对风险和适度的第二任务复核，后者先锁再看结果；不因首个任务失败而轮换数据/增强直到出现正例。11 月 4 日若只完成一个任务，可交付清楚的开发研究，不能冒充已验证的一般规律。

因此：主线 conditional-go 是准许设计一个明确的小实验，不是宣告原创成立。若时间/资源只能支持一次小样本或不充分训练，应保留为可行性研究，不提升结论等级。

## 唯一备选：增强顺序与来源面积目标的一致性

### 只问这一个问题

“对 CutMix 后执行的同一组 RA 图像，使用变换前面积标签，和使用同步运输的空间来源比例标签，是否会产生具有实用量级的干净分类错误率差；后者能否接近标准 RA→CutMix 顺序？”

主要预测：修正来源比例后，错误率下降至少 0.3 个百分点，并在预定 3 个配对种子上同向；修正流程距标准顺序不超过 0.3 个百分点。阈值是开发决策门，不是 p 值。若没有改善、只改善 NLL 而错误率失败、种子不一致，或仍明显劣于标准顺序，均保留为阴性或有限测量，不改主指标。

### 为什么它与最近邻接近、又具体差在哪里

[OA-CutMix，arXiv:2606.04820v1](https://arxiv.org/html/2606.04820v1) §§3–5、Appendix A 已经使用预先分割的物体 mask 修正 CutMix 目标，并让 mask 与几何增强同步；scratch 配方含 RA，fine-tuning 配方在附录中使用 color jitter。它研究的是物体可见面积与矩形面积的差别。这里不用外部分割器或物体 mask，只记录输入来源随空间操作的变化；同一张 post-mix 图像的 stale 与 transported 目标构成直接受控比较。实读部分未见该顺序与来源运输对照，但基本“同步变换 mask/目标”的思想已被覆盖，增量是特定工程流程的测量，不是新标签修正原理。

[Keras 官方示例源码](https://github.com/keras-team/keras-io/blob/master/guides/keras_cv/cut_mix_mix_up_and_rand_augment.py) 的最终训练管线先执行 RA，再执行 CutMix/MixUp。因此不能声称主流实现普遍存在 post-mix 来源面积错误；备选只有在批量 GPU 增强、可组合流程或实际需要交换顺序时才有工程动机。这个必要性低于主线，是选择它时必须接受的风险。

### 操作定义与标签边界

设 M 为来自 B 的 CutMix 区域指示图，混合图 x=(1−M)x_A+Mx_B，原目标系数 λ_old=mean(M)，采用实际裁剪后的框面积，soft target 为 (1−λ)y_A+λy_B。对后续几何线性重采样器 T，以相同坐标、插值和零填充运输两张来源场 a=T(1−M)、b=T(M)，设 λ_new=sum(b)/(sum(a)+sum(b))。多次几何操作逐次运输；其他外观操作按约定不改变来源场；填充不归给任一输入。分母为零则记录能力失败并停止，不临时更换规则。使用 bilinear 时来源场是连续质量，不能随意改用 nearest 再称其符合该重采样约定。Sharpness 等外观算子可能混合邻域信息，量化也有非线性，所以这里精确定义的是几何来源质量，不是整个 RA 算子后的完整像素强度归因。

λ_new 只与这一“输入来源质量”约定一致。**它不是语义正确标签或人类识别概率**；少量物体区域可能保留决定性线索，面积平衡也可能不合适。RA 可能裁掉可辨识部位或产生不合理外观，来源运输无法修复。性能改善没有数学保证，正因如此才是可证伪训练问题。不能从来源面积误差本身推出泛化改善。

### 最小数据路线与真实训练

最低成本开发路线选 [Zalando 官方 Fashion-MNIST](https://github.com/zalandoresearch/fashion-mnist)：官方 README 明确给出 MIT 许可、60,000 张训练图与 10,000 张测试图。开发只需训练图约 26 MB 和标签约 29 KB；以后确认才取官方测试图约 4.3 MB及标签约 5.1 KB，均是官网列示的近似大小。本轮未下载。保留许可通知。官方没有提供可靠商品身份组：只能以原始图像 ID 为最低单位，不能称为 60,000 件独立商品。

从训练部分按固定 seed 每类留 500 张开发图，其余 55,000 张训练；不看官方测试结果选方法。原始服饰类别标签在小幅几何/外观变化下可保持，但类别的可辨识性不获自动保证。28×28 灰度和背景简单也使它不足以支撑自然图像的一般结论。它是开发证伪池，不是因方便便宣称最终贡献。

使用 CIFAR 式小图 stem 的 ResNet-18（输入 1 通道、3×3 stride1、无首个 maxpool），从随机初始化完整训练，所有表示层可训练。保留 native resolution，不使用预训练权重或冻结特征。SGD momentum .9、weight decay 5e−4、batch128、初始 LR .1、cosine、100 epochs 是一个可锁的起点；这些是拟议值，未宣称已验证。RA 实现版本、池、N2/M9、插值、fill、CutMix Beta(1,1)及发生概率全部锁定。不混入 MixUp、label smoothing、RandomErasing 来掩盖目标差异。

### 四个条件与公平性

| 条件 | 图像 | soft target | 用途 |
| --- | --- | --- | --- |
| 标准强基线 | 每图 RA 后做 CutMix | 实际 box 面积 | 与正常训练实践比较，不能只战胜人工坏流程 |
| post/stale | CutMix 后 RA | λ_old | 待测流程 |
| post/transport | 与上一行逐像素完全相同 | λ_new | 主配对对照，只改变目标 |
| post/permuted | 同样的 post 图像 | 在同一 epoch、同一有序类别对内预先置换 λ_new | 保留该类别对的系数多重集和总体类别目标质量，检验是否需要“该图像与其目标”对齐 |

后三格共享所有输入配对、框、空间参数、图像和更新数；置换在读性能前固定，目标元数据可预先生成，不需缓存图像。第一格保留 canonical 独立逐图 RA，不能为了让对照相等而把标准方法削弱；它和 post 格的图像分布不相同，因此只能作为实用参照，**不把第一格与第二格的全部差别归给目标**。

四条件×3配对种子，共12次完整训练。先由父线程用合成输入计时估计矩阵成本，科学数据与结果不用于配置选择；只有完整矩阵可在预先允许的 Mac 资源/时间内完成才执行。建议资源上限是累计 6 GPU 小时、单进程、8A 优先，超出则备选停留在设计，不申请 A100、不削短训练后包装成功。上限是建议准入条件，不是耗时预测。所有条件计算同样的来源场；对无需修正的格也计相同记账开销，另报实际吞吐。

先做不涉及图像语义的确定性一致性检查：identity 和纯非空间操作应 λ_new=λ_old；平移/裁切/旋转的来源场与手工小数组结果一致；后三格增强图像哈希一致；目标和为1且合法；permuted 在各有序类别对中保留系数多重集。它们只证明实现正确，不能替代训练。

主指标预锁为干净开发错误率，主差为 E_post/stale−E_post/transport。NLL、校准、来源质量差 |λ_new−λ_old| 分布为次要诊断，完整报告，不因哪个显著而替换。run 为训练重复单位，图像为固定模型评估单位，CutMix 对和增强样本不算新独立物体。3种子只足以作开发筛选，若成功还需新的预锁确认；不能靠开发图 bootstrap 或许多增强样本把小种子数伪装成充分统计证据。

### 何时值得、何时停止

它的价值是能把“流程顺序造成的输入分布差异”和“同一输入上的来源目标差异”分开，并可用两色来源图/填充区域作直观展示。如果修正只是在人工 post-mix 流程里有很小效果，而正常强基线更好，就应报告这一有限事实并结束，不能升级为新的通用增强方法。Fashion-MNIST 正例本身也不够形成自然图像贡献。

若以后需要自然图像复核，只在这个同一问题内预锁一个合规数据集；本轮不新增候选或下载。已读 [CIFAR 官方页面](https://cave.cs.toronto.edu/kriz/cifar.html) 列数据与引用要求，但未在该页面找到明确数据许可，不能把库代码许可替代图像许可，也不能声称许可链已完成。这是资料未核全，并非下载遭拒。

## 执行边界与交付判断

本轮应先推进主线的完整训练可行性与协议锁定。备选留作主线因资源/结果失败时的单一设计储备，不同时撒网。两者即使得到阴性结果也能按预定问题讲清楚，但“老师觉得厉害”应来自设计、近邻辨析、可复算证据和诚实范围，不能由表述放大代替。

本审查未遇到新的工具拒绝或验证页。未新增模型、数据或训练产物；历史不可访问来源保持停止。旧 smallNORB、qB/qS、FFR/ForAug、代理错误候选、封存测试和课堂材料没有被复活或改动。
