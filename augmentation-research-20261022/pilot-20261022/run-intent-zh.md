# 本轮执行范围与可检验问题

继续原 RandAugment 项目，研究已不限定因果。唯一要跑的问题是：同一个 ImageNet ViT-B/16，在相同可训练参数、数据曝光、优化配方和增强图像轨迹下，Q/V-LoRA 放前3层还是后3层，是否改变固定 RandAugment 的干净分类收益？主量是两种布局的增强收益之差 I；不是找四格中最好看的一个。

本轮只做四格、一个事先指定种子20261022的开发 pilot。两布局各36,864适配器参数加28,453分类头参数；共同 AdamW adapter LR3e-4、head LR1e-3，不搜索学习率。强参照全层r1、全层r4和完整微调尚未运行，备选也不开训。单种子不足以确认训练随机性下的稳定性，更不足以宣布原创贡献。

训练前依次保存：当前官网许可与来源完整性、重复与可见性 QA、虚拟标签资源计时、正式协议与代码/SHA锁。原草案10epochs仅370个逻辑更新，最多30epochs已在草案范围内；为避免纯粹欠训练，预先用资源规则决定：如果实测30epochs四格 compute+pacing 估计加25%余量不超过2小时，则四格都30epochs；否则都10epochs，若仍超预算就不启动。假标签计时模型全部丢弃，不查看任务准确率或损失数值。

I≥1个百分点是原提案的继续投入尺度，约相当于592张图中6个净错误计数单位，不是显著性、功效或等效界。主端点固定最后epoch，micro错误率；macro/NLL/各类与曲线完整作次要诊断。固定模型的配对、按品种保持计数的照片 bootstrap 只检查开发池抽样敏感性，不含训练seed变异，也不证明未知动物身份独立。若RA两布局都伤害性能，正I至多是伤害程度差异。

增强沿用14操作池N2/M9，而不是因为某些图难看就改小强度。来源品种标注保留，但crop/颜色可能破坏可见品种证据；trimap与37张预选真实图的审查不等于全体增强都保标签。测到交互也只能先解释为共同配方下的经验现象，普通优化难度和语义线索损伤仍可能解释它。

近邻边界沿用主目录 evidence：Surgical FT 已有位置×移位，Hint-Aug 已有细粒度PEFT强增强损伤，DynamicAug 已有LoRA动态增强，CoCa 已有LP/LoRA增强差异。已读可访问部分没有这里完整的等预算位置×固定图像轨迹四格；这不能证明无人做过。历史验证页、403与不可访问页面不重试或绕过。
