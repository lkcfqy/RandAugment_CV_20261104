# 训练视图 CPU 配对核查：分数变化，但零预测翻转

2026-10-23。本轮已完成 37 张固定训练图 × 两个现有 checkpoint × weak/RA 两种视图，共 148 次前向。主要方向检验的两个均值均为负，但两模型在两种视图上均为 37/37 正确、零预测翻转。因此只保留“模型分数对输入增强有响应”的观察；尚无本批实际分类损害、品种语义破坏或开发共同错误成因的证据。

## 固定比较与实际预算

读取并遵守 protocol.json 的冻结上限：首图预检 4 次、30秒；通过纯资源门槛后复用这4次，至多再144次，合计120秒。图像来自原591张训练白名单，每品种按source_id取第一张，共37张；该选择在本轮任何图像解码与前向前落盘。模型为原epoch30的 front-weak 与 front-ra，seed20261022。原预训练权重、14个可训练参数张量的恢复值、完整冻结参数摘要均核对通过；没有训练或优化器。

每图使用原 common.py 的 seed20261022 / epoch0 弱裁剪与翻转，以及 torchvision N2/M9（31档）完整14操作池。记录实际有符号幅度和生效参数；跟踪过程与原未插桩函数逐字节一致。相同像素与归一化 tensor 输入两个checkpoint。最近竞争类先由 front-weak 的 weak 视图确定并固定，另记动态最强非真类和各模型自己的 weak 固定竞争类。

预检含进程启动退出 **2.027745秒**；冻结投影34.962311秒，通过后续门槛。续段 **11.684704秒**；合计 **13.712448秒**，峰值 **1182203904字节（1.101GiB）**。CPU FP32、intra/inter-op均1、nice10。累计前向wall 9.820346秒，进程CPU 9.806376秒，未触发自身等待比例阈值。GPU前向0，新增训练0。此前ps查询被拒，未重试；这些自身计时不证明8A完全空闲。

## 全部37张的结果

所有差值均为同一图 **RA视图减weak视图**，不是两个训练方法间的准确率提升。

| 指标 | front-weak | front-ra |
|---|---:|---:|
| 真类概率平均变化（百分点） | -1.477504 | -0.511078 |
| 真类概率变化中位数（百分点） | -0.029340 | 0.001616 |
| 真类概率下降 / 上升图数 | 21 / 16 | 18 / 19 |
| 固定竞争类概率平均变化（百分点） | 0.537746 | 0.108810 |
| 固定竞争类 logit margin 平均变化 | -0.132804592 | -0.002263800 |
| 动态最强非真类 margin 平均变化 | -0.200372079 | -0.075550455 |
| NLL 平均变化 | 0.016492216 | 0.005428203 |
| weak / RA 正确数 | 37 / 37 | 37 / 37 |
| top1预测翻转数 / 动态竞争类切换数 | 0 / 9 | 0 / 8 |

均值和中位数不同，不能写成普遍恶化。原方向检验仅在这37张训练图的一次预定轨迹上保留，不是显著性检验。事后删一图描述中，主模型概率和固定margin均值仍为负；RA模型固定margin均值范围为 **[-0.055127, 0.051028]**，跨0。后者“几乎零均值”不能当普遍不变性证明。事后结果和所有上升反例完整保存在 posthoc-description.json / paired.csv。

主模型最大下降图 staffordshire_bull_terrier_105 的真类概率由94.61%到73.60%，仍预测正确；原轨迹为AutoContrast后ShearX，动态竞争类从american_pit_bull_terrier转为american_bulldog。该样本解释了主模型有符号总概率变化的38.44%，三张最大下降图合计63.94%，说明分布偏斜。

另保留 Sphynx_103 反例：原轨迹连续两次向上TranslateY各30像素，保存图中可见下侧填充及耳部上缘裁切，主模型真类概率却从98.50%升至99.24%。这些是事后展示样本，不用于重新选择实验图像。视觉查看只确认可见变化，没有做专家品种语义裁定；111张原图/weak/RA PNG均本地保留。概率下降不能直接叫“证据被删”，概率上升也不能证明标签语义完整。

此前开发集 back 组32张共同错误的 max-confidence 平均差为−0.0001478412，仍不支持统一的“RA增加错分置信度”；原NLL均值差约+0.03080015而中位数约−0.04000993。本轮没有重测或撤销这组反例，没有重启已关闭的LoRA位置交互。

## 直接先例与实质差别

- [Ctrl-A（2026）](https://arxiv.org/html/2603.21819v1) §3.3用增强/原始验证准确率之比衡量各操作响应，结合train/val loss调强度；§3.5明确用验证而非训练图。本轮只是固定训练视图审计，不足以否定该方法，也不能把记录连续margin包装为新控制器。
- [May等，2026-10-05](https://arxiv.org/html/2610.06146v1) 比较partial RA等增强下的AUC与ECE。本轮是固定37分类分数响应，未评估校准或建立训练泛化因果结论。
- [Kirichenko等，NeurIPS2023](https://arxiv.org/html/2401.01764v1) 已研究细粒度混淆与类别条件干预；本轮没有提供新的语义损失机制。
- [Affinity and Diversity（2020）](https://arxiv.org/html/2002.08973v2) §3.1已用固定模型在原始/增强验证集的准确率差描述增强分布偏移；输入敏感性并非新的研究原则。

最新论文比较和访问范围见 literature.json；未穷尽前作。IEEE页面此前遇验证阻断，ExploreAugment的OpenReview验证阻断也未重试或绕过。
