## 精确问题与可证伪预测

在同一 SRA 式强度公式、优化节奏、训练图像与固定人工错标机制下，错标仅进入控制器时的影响，是否不同于它同时进入监督损失时的影响？

候选有害假说 H1：在损失标签固定为带噪的条件下，控制器也使用带噪标签会提高干净开发集错误率，即 `ΔC|L1 > 0`。加性交互 `I > 0` 是更强的次要假说，H1 不必推出它。允许零效应或负效应；不能事后把相反方向改写成原假说成功。

“同一个错误类别被两次使用导致额外伤害”不是四格本身的假说；若保留这句话，必须增加下述第五组。所有效应均限于被测数据/模型/噪声机制。未设科学等价界；不能以未显著或某个工程百分比判定机制不存在。

## 标签与数据

候选数据为 [Fashion-MNIST 官方仓库](https://github.com/zalandoresearch/fashion-mnist/tree/b2617bb6d3ffa2e429640350f613e3291e10b141)：60,000 张训练图、10 类、28×28 灰度；官方仓库的 [MIT LICENSE](https://github.com/zalandoresearch/fashion-mnist/blob/b2617bb6d3ffa2e429640350f613e3291e10b141/LICENSE) 已读取。拟只从官方训练部分固定抽取每类 600 张拟合、每类 200 张开发，共 6,000/2,000，二者不交叠；官方 10,000 测试和剩余样本封存。不下载或读取测试文件。本轮连训练图也未下载。

原数据标签记为 y₀，不假设它们绝对没有自然错误。训练集内每类固定抽 20% 位置，改到其他 9 类；类别转移数预先平衡并保存，得到 ỹ。开发标签不污染。20% 是一个避免噪声率搜索的设计选择，不是有效/无效阈值；若后续认为场景不合适，应在任何结果产生前修改并保留版本。

初始化、采样顺序、错标图、增强随机数分别设独立随机流。拟采用 3 个预先登记的重复运行 ID，所有组在同一 ID 内共享初始化/数据顺序/错标图/增强随机轨迹。3 次只能作探索，不能宣称充分统计功效；不足时如实报告，而不是按结果补有利 seed。只固定一个数据划分，限制结论外推。

灰度数据上颜色算子会退化，强几何/反相也可能改变类别语义。实验启动前必须固定有任务依据的算子集合及范围，检查训练图上的语义可接受性并保存；不可照搬 RGB 14 算子后宣称完整复现官方 SRA。若只保留适当的小算子集合，报告名称应为“SRA 式评分机制的受限实验”。此项尚未执行。

## 四格及代码改造点

每个训练样本必须返回 `(index, image, y_original, y_corrupt)`；`loss_target` 与 `controller_target` 分别从这两列选择，不能原地覆盖 dataset.targets。

| 组 | loss_target | controller_target |
|---|---|---|
| 00 | y_original | y_original |
| 01 | y_original | y_corrupt |
| 10 | y_corrupt | y_original |
| 11 | y_corrupt | y_corrupt |

对应官方 SRA 的改造位置：[SRA_CIFAR.py 第 194–238 行](https://github.com/ainieli/Sample-awareRandAugment/blob/785c3b12944251af81201083a9698a87f1d490f2/SRA_CIFAR.py#L194)。逻辑伪代码如下，**不是已执行代码**：

```text
for fixed minibatch and fixed shared random trace:
    B1, B2 = split_into_equal_halves(minibatch)
    yL = select_label_array(loss_route)
    yC = select_label_array(controller_route)

    # 保持原随机探索半批的更新节奏
    m1 = shared_uniform_magnitudes(B1)
    update_classifier(CE(model(augment(B1.image, m1, trace1)), yL[B1]))

    # 使用同一基本视图，不因组别重新裁剪或翻转
    with no_gradient:
        p2 = softmax(model_for_score(B2.basic_view))
        m2 = (p2.gather(yC[B2]) / l2_norm(p2)) ** (2 / log(C))
    update_classifier(CE(model(augment(B2.basic_view, m2, trace2)), yL[B2]))
```

第一半批的监督标签也必须跟随 L；否则所谓“损失标签污染”只污染了一部分更新。评分必须在第一步更新之后。保持两个 optimizer/scheduler 更新，以及评分前向的位置。对包含 BN/Dropout 的模型，所有组共享 mode 规则与随机轨迹；`no_grad` 不是 `eval`。新小 CNN 可明确选无 BN/Dropout 来减少状态路径，但那属于受限机制实验，不能代称官方 WRN/ShakeShake 结果。

采用独立小 CNN（例如两个卷积块加分类头），不接旧 LoRA/ViT/checkpoint。正式启动前另行冻结架构、优化器、学习率、epoch、算子范围、数值精度和耗时预算；本草案故意不伪装成可直接启动的最终配置。代码路由可实施并不代表这些科学设计项已解决。

## 必要对照和它们能排除什么

1. **标签无关强度基线，L0/L1 两组。** 保持两个半批更新、相同评分前向及算子抽样，只用独立于标签的预定随机强度。不要把这套节奏称为普通全批 RandAugment。它能帮助区分一般监督噪声效应与控制器附加效应。
2. **接口负对照，不需新训练的逻辑检查。** 在固定 logits、固定模型/策略状态和随机轨迹下，标签无关分数（例如预测熵）切换 yC 应逐项不变；SRA 分数应符合公式。此检查尚未执行，只验证路由，不证明训练收益、可靠性或新颖性。
3. **如果主张“同一个错误”的特殊作用，必须增加独立错误类别组。** 保持 L1 的错标位置和标签不变；控制器在相同位置独立抽取非原类别，错误率和按原类别的转移计数匹配，记 Cind。比较 E11 与 E1,Cind。同类内随机重配错误类别可保持计数；不要强制所有重配标签都与监督错误不同，否则改变独立性。记录实际标签一致率。此对照隔离错误类别的共享，不隔离错标位置的共享；不能越界解释。
4. **如果主张强度分配本身，另需边际分布匹配。** 仅切换 yC 同时改变平均强度及分配。预设同强度集合的重分配/冻结回放可追问分配作用；在本四格未显示有意义的问题前，不自动扩张这一额外实验。

四格不是自然直接/间接效应的完整因果分解。训练反馈会使各组参数和未来分数不同；它识别的是指定算法级干预的总效果。共享随机数有助比较，不会让不同训练轨迹自动等价。

## 输出、停止与资源

主指标：预先固定终点的干净开发错误率，报告每次重复和均值。对每次重复计算 `ΔC|L1 = E11−E10`、`ΔC|L0 = E01−E00`、`I = ΔC|L1−ΔC|L0`；另外报告各原类别及错标位置的强度统计，以核对干预确实到达增强器。开发图像 bootstrap 只能作为条件图像不确定性，不能替代训练随机性；三重复结果也不得包装成普适结论。禁止选择最好 epoch/最好 seed 作为主结论。

最低解释预算：四格 + 两个标签无关基线 × 3 次重复 = 18 次小模型运行；若声称“同错标”的额外影响，则为 21 次。不是四次短跑就能证明双重伤害。CPU 墙钟时间尚未测量，不能保证在一小时或本轮 45 分钟内完成。后续若获准进入实现，先进行有上限的本机 CPU 预检并报告总预计资源；未经报告不启动长训练。MPS 要单独正式审批；A100/任何收费 GPU 要先询问，不能沿用别的任务授权。
