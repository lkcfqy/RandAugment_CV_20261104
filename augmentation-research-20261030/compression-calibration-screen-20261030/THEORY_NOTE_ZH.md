# 配对预算的已知方差关系：推导检查

2026-10-30。纸面解析推导，没有运行数值/模型。属于经典分层/反变量方法的实例，不宣称新定理。

固定某一类别、一个观察位置和两个预先固定量化候选。令该类别校准来源池有 N 个来源，a_i=d_0(x_i)、b_i=d_1(x_i)。令 S_a²、S_b²、S_ab 为使用分母 N−1 的有限总体方差/协方差。该类别每臂有 B_c=2n 次 forward。

P 对从 N 个来源简单随机无放回选 n 个，每个取(a_i,b_i)：

V_P = (1−n/N)(S_a²+S_b²+2S_ab)/(4n)。

I 从同池取两个互不交叠的随机组 J,K，各 n 个，J取a、K取b。由于来源不同，Cov(mean_J a,mean_K b)=−S_ab/N。因此

V_I = (1−n/N)(S_a²+S_b²)/(4n) − S_ab/(2N)。

两式相减恰得 V_P−V_I=S_ab/(2n)=S_ab/B_c。多个独立类别分层，目标类权重 w_c，差为 Σ_c w_c² S_ab,c/B_c。这里没有假定图像分布镜像不变；两组估计相同的各视图50:50混合均值。

这不等于“每个实现的经验样本多重集相同”。若输入激活多重集完全相同，只有配对标签改变，确定性的无状态目标均值和argmin必须相同。原生histogram更新若对顺序敏感，则另需状态控制，不能把它归为本题联合分布效应。

限制：

1. 该等式只针对固定候选损失差的方差；数据依赖地重定候选/网格不满足前提。
2. 低方差不蕴含一侧尾概率、多个候选的argmin出错率或任务NLL严格降低；只能在额外分布假设下给近似或上界，不能偷换成因果定律。
3. 预测pilot不属于上述校准来源池；其估计的协方差必须在独立来源上验证，不能以同一批数据代入两端充当实证。
4. 自然clean目标与镜像混合目标可能有不同最优量化器。P/I边际相同排除的是两者间的目标改变，不排除它们共同偏离clean目标。

来源关联：[Chen、Dobriban、Lee，A Group-Theoretic Framework for Data Augmentation，JMLR2020，§3.4/4.2/4.3](https://jmlr.org/papers/v21/20-163.html)。本推导的有限池代数由本轮独立写出，并未声称原论文给出了以上同一PTQ实验。
