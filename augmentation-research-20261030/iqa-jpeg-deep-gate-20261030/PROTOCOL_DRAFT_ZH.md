# 最小观测协议草案（未执行，待 Pro 审查）

本稿只围绕同源 JPEG 质量变化。不是实验授权，也不修改旧封存测试。预计下一动作是合法取得并核验官方评分元数据；所有模型阶段继续单独审查。

## 数据、单位和事件

固定载体：LIVE Wild Compressed Picture Quality Database。i=1..80 表示原始内容；j=0 为已有真实拍摄失真的源图，j=1..4 为从该源图分别生成的官方 JPEG 版本。不能把它们写成 pristine，也不能把四个版本误作依次重复编码链。

每个源内容等权。独立内容最多 80 个，不将 400 张图、320 条源→JPEG 关系或 bootstrap 重复当作独立部署任务。

人类真实均值记 μ_ij，变化 Δ_ij=μ_ij−μ_i0，正值代表改善。本稿不把 MOS 当无噪声真值，也不把任意 5 分差称作 JND。

## Gate 0：只读评分与 CPU 统计

1. 通过官方允许的渠道取得评分表、source ID、版本/质量参数、受试者 ID、session、原始或作者标准化分数、保留/排除标记及 README。记录来源、许可、哈希、完整字段；不靠第三方镜像绕过申请。不需要接触图像文件。
2. 核验 80×5 映射、作者评分方向及 MOS 重现。若需要作者原始规范之外的选择，先报告；不自行删评分者使结果显著。若只有 MOS 而没有可信的不确定性资料，报告描述统计与识别不足，不把小差判成改善。
3. 若逐评分者记录可得，按作者保留名单和原始 session 规范生成同一人的成对差。固定拆分规则：对保留的受试者 ID 以 SHA256('IQA-JPEG-20261030:'+ID) 排序，前 11 与后 12 为两组；实际人数与论文不符先查明，不默默适配。
4. 报告全部 320 个成对差、组内变异、两组方向一致性。双侧成对检验对这 320 个关系用 Holm 控制 0.05 家族错误率；同时给出效应大小及假设边界。成对 t 检验仅为评分差近似均值推断，不当作无分布保证。补充按受试者配对重采样的区间，不因二者不一致挑有利结果。
5. 预设“可投入下一步”门：至少 8 个不同源内容存在均值为正、两评分组均为正且 Holm 检验通过的源→JPEG 关系；并有至少 8 个源内容提供同标准的变差关系作方向控制。8 是廉价初筛投入门，不是充分统计功效或论文级系统性证据。报告所有关系，不能只留这些内容。
6. 没有这类支持：结果是这份载体对该问题不充分或改善未被确认；不称模型机制无效。少量或边界不确定结果：记未决，停止后续模型投入；不扩参数、换档位或挑图。

成本：无需 GPU/权重/图像。表格解析及上述统计设 CPU 计算上限 10 分钟，实际耗时另记录。数据申请与字段补齐时间不计为计算；不承诺文件现在已在本机。

## Gate 1 草案：Gate 0 后另审，冻结推理，不训练

处理全部 400 张官方原图/版本。固定官方 TRIQA KonIQ head 与 ARNIQA koniq10k head；新下载的权重必须先锁定哈希、验证归档及加载方式。不得以 LIVE/CLIVE 头替代以免同源内容重叠不清；KonIQ 与本库的内容重复仍需来源/哈希核验，不能仅因库名不同宣称零泄漏。

两模型采用作者发布的推理预处理：TRIQA 全图与半图、content/quality 两支；ARNIQA 官方单图脚本的中心/四角、全/半尺度。固定 float32、eval、无随机 TTA。两管线推理开销不同，如实计数；这不是等架构训练干预。所有 score、embedding 与线性头元数据一次缓存，禁止挑图或重新调预处理。

主比较还包含不压缩的保守政策，以及官方 2stepQA/MS-SSIM 的结构性基线。2stepQA 与 MS-SSIM 在源图因子为正时具有相同组内排序，不把它们算两份独立排序证据。NIQE≤0/≥100、非有限值和加载失败都记录，不临时裁剪分数改变排名。

固定选择器：对每张源图，比较五个版本的模型质量分数；仅在某 JPEG 分数严格高于源图时选最高者，否则保留源图。并列优先保留源图，其次较轻压缩。纯浮点近等视为 tie 的相对容差 1e−7 预先固定，不能依据结果调节。

主要部署量：G_m=(1/80)Σ_i[μ_i,a_m(i)−μ_i0]，以及选择了人类明显变差版本的源内容比例。模型选择不读本库评分，故评估不对同一 MOS 先挑“最佳版本”再算乐观收益。各方法作配对内容比较，并在可得时把受试者重采样纳入不确定性；不能把重采样轮次当新增样本。

诊断量：正向关系漏检、负向关系误报、组内排序，以及总体 SRCC。只有反例、总体相关性差异或 latent 距离差异不构成通过。严格单调标量重映射不能改变选择器；若只测绝对质量阈值，那是另一个需要校准集的问题，本稿不据此救题。

竞争解释：
- 稳定人类改善存在而 TRIQA 选择器漏掉，ARNIQA 在同一组内容得到可靠收益且没有更高损害，才值得讨论管线的用途边界。
- 二者相同地失败或同样保守：不能归因于有序三元组；最多重现一般 IQA 困难。
- TRIQA 并无实质更差：否决这条具体预期，不改 head、数据或增强。
- 结果受少数内容支配、区间宽或预处理差异无法区分：未决，不包装成系统性发现。

前述正向结果仍须与现成降质参考校准思想比较，且需独立内容确认后才主张可迁移部署建议。DR-IQA 的非线性校准是强既有解释，不用只比较弱的单变量缩放来排除它；但本轮不另外拟合或调参。

预算草案：TRIQA 400×2尺度×2分支=1,600 个图像分支前向；ARNIQA 400×2尺度×5裁剪=4,000 个裁剪前向，总 5,600 个不同大小的 backbone 输入，不伪装等 FLOPs。另有 320 个 MS-SSIM 对及可缓存的源 NIQE。先固定前 8 个 source ID 作吞吐/一致性验收，其结果并入完整缓存；模型阶段墙钟上限 30 分钟，未完成记执行未决。此时间是投入上限，尚无本机吞吐观测。不得为赶上限换成更弱 ARNIQA 推理。

资源阻塞在执行前解决：TRIQA Box 链接本工具未能读取；当前作者代码在无 CUDA 时走 CPU，MPS 需透明的设备适配与小样本数值核验。ARNIQA 构造函数会额外请求 ImageNet 初始权重，需审查后采用完整 checkpoint 的严格加载或明确计入额外下载，不能误写只下载一个文件。没有任何上述运行发生。
