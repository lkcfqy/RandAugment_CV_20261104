# 单问题送审：有序失真表征的 JPEG 局部质量决策边界

2026-10-30。只读与解析，尚未取得评分表、运行模型或观察任何新实验结果。建议 Pro 目前只审查 **Gate 0：人工评分的可识别性核验**；暂不批准训练或修正增强算法。

问题：对一张已有真实拍摄失真的源图及其四个官方 JPEG 版本，TRIQA 的冻结官方评分器是否会系统性错过人类可辨别的质量改善，从而不适合直接作“质量不下降才压缩”的选择器？这种错误能否与评分噪声、整体分数校准以及一般复合失真困难区分？

选择理由：这是上一轮 RQF-2 中尚未被同一实验回答的部分。它有明确的原方法、有同内容的人类评分数据线索、可用官方推理实现，最先要解决的事实仅需评分表。预期贡献如果成立，是特定部署用途的适用边界，而非“JPEG 可能去噪”的发现，也非新损失函数。它不涉及 first-cv 的分割部署题。

## 两个以上可区分解释

1. **H-rating**：所谓改善主要是有限人类评分的噪声。预测：同内容正向差在固定两组评分者中不稳定，或同时置信区间不能与零区分。此时停止模型阶段，记录这份数据不足以检验该机制。
2. **H-boundary**：存在稳定改善群体，但冻结评分器系统性判断反向，并在预设选择规则下产生可量化机会损失/实际损害。严格单调的分数校准无法修复相对排序；若仅存在绝对分值偏差，不能支持该解释。
3. **H-generic**：TRIQA 和 ARNIQA 同样失败，或已知降质参考校准已解释问题。此时不把它归因于有序增强，也不把一般复合失真困难改名为本项目贡献。

H-boundary 仍是方法管线的适用边界；未控制的 backbone、预训练与回归头差异意味着它不是“有序三元组造成损害”的因果证明。若要作该因果主张，需要另立等数据/等预算训练干预；本稿不请求这种训练。

## 最小低成本事实

先取得官方 LIVE WCmp 评分文件与内容/版本映射，核查 **80 个源内容、每个 4 个 JPEG 版本中，有多少源内容存在可重复的人类正向质量差**。论文四档 JPEG 为 18、12、6、3；它们可能过强，根本不覆盖质量改善区。这里不能先把理论反例当成数据已包含的事件。

当前可核实：400 个图像的设计、23 名保留评分者与每人两次 session 的评分流程。尚未核实：发布包是否提供逐评分者数据、源图与版本的精确表、作者的排除与标准化字段。官方当前下载入口要求申请表，尚未提交。Gate 0 只需元数据和评分，不需要图像、模型、训练或新主观实验。

Gate 0 若通过，才另交冻结模型的单次推理协议；草案见 `PROTOCOL_DRAFT_ZH.md`。若不通过，交付全体关系及不确定性，不调 JPEG 档位、不挑内容、不改到其他指标追求阳性。没有实验结果前，不作创新成立判断。
