# MolScribe / OCSR 候选关闭与更正

记录日期：2026-10-30 UTC。状态：**NO-GO；不做此路线的符号审计、模型实验或数据获取**。

## 决策及适用范围

父任务转达实际 GPT-6 Pro 的最终评审：预计的离散标签回译差异可由已知坐标量化跨过符号解码边界解释；当前没有独立的适用性结论或训练影响证据。即使有回归测试价值，也不足以成立研究贡献。该决定关闭此前的 MolScribe 原生增强—离散标签—立体语义候选，不通过更换化学数据、坐标精度、模型或增强参数继续它。

这是候选贡献门未通过，不是已经实测 MolScribe 无效、量化没有影响或整个 OCSR 研究无价值。本任务没有执行 RDKit、图像增强、模型推理或训练，也没有取得化学数据。

## 保留原草案已有的对照

原文件 `../research-screen-20261030/OCSR_REVIEW_QUESTION_ZH.md` 已明确将 `E_Q(T)` 与 identity 的 `E_Q(I)` 配对，并要求连续路径保持原语义。其意图可写为：

`Delta = E_T[E_Q(T)] - E_Q(T0)`

其中 T0 是基准/identity。**不能把评审对“只看 E_Q”的警告记成原草案没有基准对照。** 但 Delta 为正仍可能仅体现已知量化与离散解码的非交换性，不能因此推导新颖性、网络能力上界、训练损害或实际药物性质后果。原文件保持不变，本文件只添加决策及解释。

## MolSight 更正

[MolSight v1](https://arxiv.org/html/2511.17300v1)，2025-11-21，Atom Localization 与 Appendix / More Implementation Details：

- 坐标仍按 x、y 一维分类；支持点为 `linspace(0,1,B)`。
- 附录明确 B=128。Laplace mixture 是对距离敏感的坐标损失，并非无量化的连续坐标输出。
- 本次仅核查论文，不把该解释标成 MolSight 官方训练代码验证。
