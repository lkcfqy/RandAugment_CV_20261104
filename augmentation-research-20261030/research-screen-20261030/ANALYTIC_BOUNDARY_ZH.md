# 解析边界：舍入误差不能自动成为新贡献

这里没有数值运行。以下是普通误差界推导，不能作新定理或 RDKit 手性正确性的完整证明。

每轴 B 档、区间[0,1]、最近邻舍入，步长 h=1/(B−1)，每点各坐标误差绝对值至多 h/2。取三点 a,b,c，u=a−c，v=b−c，D=det(u,v)。差向量误差 du,dv 每分量至多 h，因此

`D'−D = det(du,v) + det(u,dv) + det(du,dv)`

`|D'−D| <= h*(||u||_1 + ||v||_1) + 2*h^2`。

若 |D| 严格大于右边，单个二维三点方向不会因该次舍入改变；等号/边界不能保证。正行列式的精确仿射变换本身保持 D 的符号，但变换后的归一化、几何间距和网格相位会改变舍入风险。

这仅约束一个方向谓词。RDKit 还使用键方向、局部拓扑、隐式氢、手性定义和异常处理；并不由一个三点符号独自决定全部立体化学。原生 SafeRotate 的 int、crop/clip 和 pseudo_coords 路径也不属于上式的单次末端舍入假设。

因此：

- 构造近共线反例容易，不足以立题；需实际正常链和未挑选数据的事件频率。
- “更多bin降低误差”是已有解释，不能独立称新方法。
- 某个正确量化标签回译失败不等于整个离散表示无法表达该分子，更不等于训练后模型一定受损。
- 不能据此生成“已经证明增强破坏手性”的结论；本轮没有运行任何图像或符号转换。
