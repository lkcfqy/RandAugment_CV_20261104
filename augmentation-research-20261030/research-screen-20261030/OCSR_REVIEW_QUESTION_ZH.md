# 仅供评审：原生几何增强后离散标签的立体语义一致性

状态：**未验证假设，不是贡献；没有实验准入**。与刚关闭的多视图联合量化无关：这里不汇总多个模型响应，也不估计类别比例，而是检查单个带图结构标注样本的确定性标签编码与符号解码是否相容。

## 问题和唯一差分

对一个真实、可表达的分子图，原子和键类型全部正确、连续坐标足以恢复正确立体化学时，采用作者正常几何增强及 64 档训练标签后，完全正确的离散标签经作者符号解码器能否仍保持同一个立体化学结果？正常增强是否增加这种**目标标签回译不一致率**？

这不是问神经网络是否会预测错坐标，也不是问更大图像、更细网格或更好的损失是否提高准确率。它与普通数值误差只有在真实原生支持下出现足够频繁且具有实际成本/语义后果时才可能有实证增量。若只是少数手造近共线点、已经错误的注释或提前 int 转换造成的局部实现问题，就关闭。

令 u 为连续坐标，g 为正确 symbols/bonds，S 为固定符号解码器，T 为原生变换及其实际归一化，Q 为作者 64 档 round-trip。考察：

`E_Q(T) = 1[S(Q(Tu),g) != S(Tu,g)]`

同时验证 `S(Tu,g) = S(u,g)`，并与 identity 的 `E_Q(I)` 配对比较。若连续路径自己就变了，归入变换/解码不适用或注释问题，不计入离散标签机制的阳性；仍保存全量原始类别和分母。

**关键限制**：即使 E_Q>0，也不能称所有网络都无法预测正确、模型能力的不可逾越上界或表示空间的信息论不可能。网络可能选择邻近网格点来保持语义；这里只审计既定监督标签的回译。普通坐标舍入不与旋转交换也不是新定理。

## 若评审认为值得，先决阶段草案（未授权执行）

1. 先解决数据：需要图像、独立人工图标注、连续坐标、定向 wedge/dash 约定、可核验使用条件。MolRecBench-Wild 只有 test split且许可未声明，当前只是元数据候选；不能先看错误再挑子集。无合格数据则不启动，不能用手造几何替代真实发生率。
2. 在看结果前限定可表达的普通分子，按来源文章/分子身份去重分组；规定所有排除项与完整分母。原有 Rand 封存测试绝不使用。新 benchmark 若用作探索，必须明确失去确认集身份。
3. 固定作者 commit、RDKit/Albumentations 版本、坐标约定。完整图像变换决定 CropWhite 边界，所以不能只旋转一个坐标数组便自称复现原生链。区分动态真实图像坐标与 aux pseudo_coords 分支。固定最多8个正常分布种子/样本，保留原生概率，不增加 padding/角度制造阳性。
4. 同一次变换保存原始坐标、变换后连续坐标、作者 keypoint 路径、最终64档坐标、symbols/bonds、所有解码结果。分别计提前截断、最终网格、裁剪/clip、键方向映射、RDKit不支持、原标注歧义等。不得将“未指定”当作“另一手性”，不得用一般 graph exact match 掩盖或夸大立体化学错误。
5. identity、连续同链、64档同链配对是主要识别对照。较细网格只可作为已有解释的诊断，不能通过扫 B 选最好数后称新方法。原图变换所致像素插值不是此 oracle 路径的神经感知实验。
6. 预先把真实发生率低于可用阈值、只在不适用/近退化/错标/局部实现路径出现、或无法排除普通精度解释列为停止条件。阈值需 Pro 依下游代价明确冻结；本轮不凭空定“1%即贡献”。

计算草案上限可设为1000个预定样本×8视图、纯CPU符号转换，先小吞吐检查、最多15分钟实际计算。这是**未测的预算上限，不是耗时估计或已经完成**；数据取得、图标注适配、兼容环境和人工错误核验另有成本，当前不能报价“免费几分钟”。不需模型权重；后续模型训练也不自动获准。
