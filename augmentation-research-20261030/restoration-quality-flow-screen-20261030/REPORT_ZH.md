# 去噪、质量评估与光流：只读筛查

2026-10-30 UTC。本轮没有运行模型、导入模型、读取训练/测试样本、下载权重或数据、安装软件、训练、推送或付费。结论是 **0 条达到送交实验协议审查的候选**；这是对以下具体草案的证据判断，不是负实验，也不是宣布三个任务没有研究空间。

PTQ covariance-pilot 已单独归档关闭。本轮不重开它，不执行 Stage A 8,880 次或 Stage B 48 个网络。见相邻目录 `ptq-covariance-closeout-20261030/CLOSEOUT_ZH.md`。

## 1. 条件化噪声增强

草案：按真实噪声的方向/相关性选择几何增强或遮罩，以避免破坏信号。SPIDER 已针对 AFM 方向伪影定义旋转与 trace/retrace 交换；MASH 已按局部信号与噪声相关性设计遮罩、重排。故上述泛化表述没有形成独立干预。尚未知的是某个具体采集条件下的额外适用边界，但本轮没有取得一个“前作未测的条件→可观测失效→小改进”的完整假设，不能靠换设备或数据命名新题。[SPIDER，Results/Fig.2 与 Methods/Data augmentation](https://www.nature.com/articles/s41467-026-76973-8)；[MASH，§3.2–3.3](https://arxiv.org/html/2404.09389v1)。

结论：不保留这一泛化草案。没有运行去噪比较；不是声称两篇论文覆盖所有噪声条件。

## 2. 复合失真排序监督

草案：保留 TRIQA 的全部增强图像与曝光，只取消或减弱不能支持的有序关系，检验下游质量排序是否改善。TRIQA 的 §3.1 用顺序叠加失真组成三元组，§3.3 训练的是到 anchor 的特征距离排序；它不是直接训练三个标量 MOS 的排序。论文同时报告复合失真预训练的总体收益，不能从个别顺序反例推断方法总体受损。[TRIQA，§3.1、§3.3、Table 3](https://arxiv.org/html/2507.12687v1)。

“进一步压缩未必更差”已有明确先例：Degraded Reference IQA 讨论噪声后压缩的质量回升；其相关分析含客观指标，不能当成人类评分。dipIQ 则已有多个质量指标生成排序、按不确定性减弱排序损失的办法。因此，仅发现反例、用已有指标删对或加入置信权重都不足以构成当前增量。[Degraded Reference IQA，§III-B/Fig.10、§V-A](https://arxiv.org/html/2110.14899v1)；[dipIQ，§III-A–B](https://arxiv.org/html/1904.06505v1)。

真正未回答的窄问题，是在同图像、同曝光、同训练预算下，针对复合失真关系的改动能否超越已有不确定排序，并改善独立人工评分上的决策。当前尚未说明一个区别于 dipIQ 的具体规则；也未证明 MOS 顺序变化必然使 TRIQA 的距离三元组错误。官方固定树提供推理与网络定义，没有发布原生三元组生成器/训练入口。LIVE WCmp 有人工评分，但官方要求表单后发下载密码，本轮没有提交。其他数据中的中间图像、评分类型与精确配对仍需核实。

结论：当前草案不送实验；是增量与可执行证据不足，不是断言前作已经测过这个完全相同的干预。独立参考实现可以被诚实定义，但不能补齐上述科学差分。

## 3. 增强遮挡与光流损失

草案：利用已知的人工遮挡来源来调整光流监督权重，避免把增强造成的歧义当作可恢复信号。ARFlow 已区分原有遮挡与增强新遮挡，并用原图预测监督后者；SEA-RAFT 用混合 Laplace 损失处理歧义。因此，“新遮挡需要特殊监督/不确定像素降权”已有直接依据。[ARFlow，§4.1–4.2/Eqs.5–9](https://arxiv.org/html/2003.13045v2)；[SEA-RAFT，§3.2/Eq.2](https://arxiv.org/html/2405.14793v1)。

固定 SEA-RAFT 源码确认：第二帧随机擦除后保留光流，几何增强同步变换光流；擦除 mask 不单独送入损失。这不是自动成立的 bug：任务也预测被遮挡点的运动。代码事实并不能证明模型无法从上下文学习。当前没有提出相对于已有遮挡监督与 MoL 损失的不同预测，也未给出低成本可靠验证所需的数据/权重/训练预算。2026 年直接近邻 Reviving Unsupervised Optical Flow 的官方项目与作者已核实，但正文链接返回 403；不把它写成已读完的反证。

结论：当前泛化降权草案不保留。未做精度、校准或训练损害实验；没有宣布“所有人工遮挡权重方案无效”。
