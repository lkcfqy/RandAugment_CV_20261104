# Equalize 背景统计传入前景：最小 CPU 检验

完成：2026-10-21T05:44:25.883148+00:00。**出现了真实增强失败，但未验证新的配对损害机制，本方向暂不升级为候选贡献。** 所有运行和复核已完成，无资源或材料阻塞。

## 问题与最近先例的具体差异

本轮只问：同一个固定前景粘贴到不同背景后，全图Equalize产生的背景相关前景色调，是否因与背景的配对而额外损害识别？不再检验上轮缩放捷径，不换模型或调参。

- [Liang等，2024，§III-D/Fig7](https://arxiv.org/html/2308.09764v2)已经讨论背景移除与Equalize等像素增强的相互影响；“组合可能不兼容”不能作为新意。
- [Local Patch AutoAugment，2021](https://arxiv.org/html/2103.11099v2)已有区域增强策略及Equalize，不能把局部增强当新算法。
- [ForAug v4，2026，§3–4及附录D](https://arxiv.org/html/2503.09399v4)已有前景背景重组、强增强和受控背景交换。本轮更窄地检查Equalize之后前景色调与背景的联系。
- 结果后补读[SSH，2021，§3.1](https://arxiv.org/html/2108.06805v2)：前景/背景外观及LUT交叉组合也已有先例。可检验差异只有固定分类器上的精确边际保留风险审计，操作本身不新。

实验前固定的差异：**将已处理图像按固定保护区切成两部分，枚举全部交叉配对，严格保持处理后前景保护区和背景补集的边际分布，只改变其配对。** 先验原理“全图直方图受背景影响”是已知事实；须有独立源照片上的稳定额外模型损害才值得往前推进。检索仅10个聚焦查询及上述相关章节，不能声称全网没有等价先例。

## 固定实验

复用现有64张Oxford-IIIT Pet源照片、trimap、确定性合成像素和已通过正控的ResNet-18编码器。训练侧及留出侧各16张不同前景、16张不同背景；留出按4个源照片互不重叠宏块。每张前景只按预先哈希选择一个已有几何状态；更换操作和背景时不改缩放、裁剪、位置或掩码。

模型沿用上一轮冻结的保护边缘耦合训练类原型，未重新训练或调参。逐图RGB输入，经官方V1预处理；不用T、C、掩码或路径作模型特征。训练侧先看失败实例并保存冻结回执，随后运行留出侧；源照片互斥，但留出照片在历史实验中已使用，所以仍属探索性检查。

Equalize使用torchvision的PIL实现，并与Pillow ImageOps.equalize逐图比对。它是RandAugment/TrivialAugmentWide池内的无强度参数操作；这里是该操作的机制审计，没有执行完整随机策略，也不评价整篇方法的训练收益。[官方实现](https://docs.pytorch.org/vision/stable/_modules/torchvision/transforms/autoaugment.html)

每个固定前景状态有m个背景：标准Equalize图G_j切分为保护区F_j和补集B_j，交叉对照H_jk保留G_j补集、使用G_k保护区，j/k均匀枚举。源照片内两个处理后部分各被使用m次，因此边际分布严格相同。保护区覆盖所有前景及原3像素灰色边缘，补集逐像素不变。

阴性对照为固定阈值128的Solarize：它逐像素变换，预先固定前景的输出不应随背景改变，交叉配对必须生成逐字节相同的图。

预先门槛：主差值 LL(G)−LL(H)≥0.01 nat、至少12/16源照片为正、至少3/4宏块为正，并且Equalize相对无操作造成损失上升及实际前景变化。不是显著性检验，不对合成帧当独立样本。

## 具体结果

训练侧256对图中发现8例“无操作判对→Equalize判错”。准确率96.4844%→93.3594%。前4例保存在 `development-failure-1.png` 至 `-4.png`，左右依次是无操作、Equalize。它们仅用于展示，未用于挑选参数或留出样本。首例已本机查看，猫的轮廓仍清晰；未对全部变体做盲法人工标签有效性审查。

| 留出处理 | 状态数（来自16张前景） | 平均LL/nat | 准确率 |
|---|---:|---:|---:|
| 无操作 | 64 | 0.441965 | 87.5000% |
| 标准全图Equalize | 64 | 0.500308 | 76.5625% |
| 边际相同、交叉配对 | 256 | 0.501962 | 77.3438% |
| 固定阈值Solarize | 64 | 0.522019 | 81.2500% |

主差值 **-0.00165441 nat**，方向与假设相反；10/16源照片为正，仅2/4宏块为正，预定筛选未通过。4块差值为 `+0.00429498, -0.00356862, -0.00850671, +0.00116270`。

Equalize相对无操作损失增加0.058343 nat，准确率下降10.9375个百分点，确有增强失败。16/16留出前景的保护区颜色随背景改变，背景两两比较平均像素绝对差为26.755/255。然而打散关联未降低平均损失，不能把这些失败归因于所提出的配对机制；准确率的小变化不能替代预定损失指标。

## 复核、边界与取舍

- 重构并核对全部1,216张模型输入的RGB SHA256；独立math.fsum重算全部损失，最大误差9.44e-15，判定全部一致。
- 留出16个前景的保护区/背景补集边际，共32项精确像素分布校验通过；Solarize共4,352次交叉配对逐像素相同，阴性对照通过。
- 两阶段代码、方案和模型哈希固定，训练/留出前景源照片分离；上一轮交付30个载荷文件未变。编码器推理约18.50秒，两阶段总运行约22.17秒，均为单线程CPU，无新下载、安装、ARIS或GPU。

这些是受控合成图像上的对照，不是识别真实世界因果图，也不证明ForAug有缺陷。保护区包括边缘灰像素，交叉配对可能改变视觉协调性；背景内容和色调的物理独立干预未被识别。预训练与照片重合未知，样本仅16个留出前景，不能外推全部CV任务。

**本轮取舍：保留真实失败图片作为课堂解释及可复核负结果；放下“Equalize前景背景配对产生稳定额外损害”这个窄方向，不追加模型、调阈值或扩大它。** 当前已验证的只有已知原理和增强失败，没有新的稳定机制信号，不满足进入阳性候选的条件。
