# 训练增强价值检验：过滤选择与原图重加权

完成：2026-10-21T06:01:20.655728+00:00。**本轮实际拟合了分类读出，在此前未读取过的64张原始照片上一次评价；标签一致性过滤未通过预定训练收益筛选。** 没有追加前两条已关闭的输入敏感性假设。

## 具体问题及先例边界

问题：对单操作增强候选进行教师标签一致性过滤后，训练收益是否超过其改变原图抽样权重所能解释的部分？过滤后每张原图保留数不同，按视图等权训练就会改变原图权重；这一算术事实不算新意。要检验的是同一训练算法中“原图内部选哪些视图”是否有额外外推价值。

[ALIA，2023，§3.3](https://arxiv.org/html/2305.16289v2)已有生成与过滤，且原规则会删除高置信度编辑，本轮没有复现或重启其材料受阻的原运行审计。[DualAug，2023，§3.4](https://arxiv.org/html/2310.08139v2)已有拒绝强增强后退回基本增强的固定数量设计；本轮将其思路保留为强基线。[Sample-aware RandAugment，2025](https://arxiv.org/html/2508.08004v1)已有样本难度感知与非对称增强；[SAGE，2026](https://arxiv.org/html/2609.01051v1)已有子群定向增强。过滤、样本自适应和重加权本身都不能称为新方法。

本轮较窄的对照差异是：**在逐原图权重完全匹配的条件下，比较保留池训练和不筛视图训练，使用新的未增强照片测损失。** 已读章节没有直接建立这项构造规则下的精确分解，但这只是定向消融差异，尚不等于原创性；没有做无限制全网查新。TeachAugment的CVF页面读取返回403，未换路径重试，故没有将其全文作为已核对比较依据。确切受阻目标记录在下文。

## 数据与冻结顺序

旧64张照片已全部参加探索，故本轮把它们明确用作训练/发展材料。它们含旧实验官方trainval及test部分，这是自定义源照片互斥小样本划分，不能作为Oxford官方benchmark成绩。

新测试集从官方test清单按预先固定SHA256排序选64张，猫狗各32张；排除此前读取照片或掩码的全部128个ID，并排除既有条目的CRC重复。仅用文件元数据设每张JPEG≤512,000字节上限，没有按RGB或预测选照片。

固定先后顺序：保存问题/规则/超参与新测试ID清单→编码训练视图→四折教师及七个学生读出全部拟合并通过梯度门槛→保存模型/代码/方案哈希冻结回执→下载新64张JPEG→一次读取测试像素和评价。下载前不存在本轮测试照片目录。

实际新照片6,835,971字节，HTTP Range响应6,831,571字节，均逐成员CRC、大小、SHA256校验。未下载815 MB完整包，未下载新掩码、模型权重或依赖。镜像固定到 `003aeb4bc80d584ef307dc24e8b38d26cf9f9e43`，来源URL及每张字节数见test-fetch-receipt.json。

精确解码RGB未发现训练/测试重复；动物身份及ImageNet预训练照片是否重合未知，不能声称身份独立或预训练无泄漏。`test-consumption.json`已记录这64个测试ID，今后不能把它们当新假设的未触碰确认集。

## 训练规则

编码器为现有冻结ResNet-18 ImageNet V1的512维avgpool特征，每图特征L2归一化。先按官方V1双线性resize256/中心crop224获得PIL图，再增强，最后tensor化和ImageNet标准化。64项无操作张量与完整官方V1流程逐位一致。

每张训练照片保留1个原图锚点，加8次官方torchvision TrivialAugmentWide抽样（31个等级、NEAREST、fill128），每次单操作、随机等级，固定CPU随机种子并记录实际操作和等级。这是固定视图库的小样本读出实验，不是完整在线TrivialAugment或RandAugment训练配方。

四折教师只在该原图所在折以外的48张干净原图上拟合逻辑读出。增强视图仅在预测类别与源标签一致时保留，原图锚点总保留。因此这是自定义“标签一致性规则”，不是ALIA、DualAug或SRA原算法，也不把教师判定当人工语义有效性真值。

七个学生均训练二元逻辑回归，float64 CPU L-BFGS、固定L2系数0.001、截距不惩罚、零初始化。每个经验损失的权重总和为1，收敛门槛为最大梯度<1e-6；没有网格搜索、按测试选参数、只给某组更多优化步数或训练骨干。

按保留数k_i的过滤池，每个原图总权重为k_i/Σk。关键未过滤对照把同样的k_i/Σk分给该原图全部9个视图，精确匹配原图及类别总权重；另有等原图权重、匹配权重原图，以及拒绝后退回原图的控制。

512个随机增强中拒绝22个，加原图后保留554/576视图；每原图保留3～9个，过滤组有效源样本量约63.20（原图等权为64）。逐原图权重匹配最大读回误差3.47e-18。

## 新原始测试照片上的一次结果

| 训练数据/权重 | LL（nat，越低越好） | 准确率 |
|---|---:|---:|
| 只用原图，原图等权 | 0.178689 | 90.6250% |
| 原图+全部TA视图，原图等权 | 0.171256 | 92.1875% |
| 过滤保留池，按保留视图计数 | 0.178872 | 90.6250% |
| 不筛视图，精确匹配过滤后的原图权重 | 0.172981 | 90.6250% |
| 同一保留池，恢复原图等权 | 0.177390 | 90.6250% |
| 只用原图，匹配过滤后的原图权重 | 0.180400 | 90.6250% |
| 被拒视图退回原图，每原图固定9槽位 | 0.177088 | 90.6250% |

预先固定主收益 = LL（原图权重匹配的未过滤增强）−LL（过滤池）= **-0.00589149 nat**。按原始测试照片、猫狗分层的5,000次配对bootstrap 95%区间为 **[-0.01330894, +0.00007220]**，包含零；方向也不支持过滤收益。0.01 nat门槛、区间下界为正、过滤优于原图这三项均未通过。

全部增强训练组比原图组损失低0.007433 nat、准确率高1.5625个百分点（多判对1/64张照片）。这是预定次要对比的点估计，不能据此宣称稳定增益或达到投稿贡献。过滤组比全部增强组损失高0.007616 nat，准确率回到原图组；移除教师不认可视图在这个设置中没有帮助。

没有因结果不理想再换阈值、模型、增强强度或测试子集。主问题中本就未出现过滤收益，因此不能进一步声称“过滤收益完全由重加权解释”；主区间含零也不证明两组等价。

## 检查、成本与结论

独立读回11个逻辑优化目标及四折来源隔离；学生目标最大误差5.55e-17，最大梯度2.71e-07，均通过。全部测试预测按独立math.fsum重算，损失最大误差4.44e-16；配对bootstrap区间复算一致。

训练编码约8.44秒，含读出拟合训练阶段约8.96秒；新测试编码约0.94秒，测试阶段约1.18秒。全程单线程CPU，未调用ARIS/GPU/A100、未改8A或全局配置、未上传。新照片下载成功，无运行/材料阻塞。

**取舍：本轮已把研究对象纠正为训练增强价值，但这个标签一致性过滤规则没有获得超出原图权重控制的阳性证据，不升级为候选贡献。** 保留七组完整训练结果、真正未触碰的新测试记录和阴性结论；不追逐该规则的正结果。

证据范围是冻结表征上的监督读出训练，端到端训练收益尚未测试。只有64张训练原图、一份固定增强视图库及64张新测试照片；bootstrap只反映固定训练模型下的照片采样变化，不覆盖训练数据/种子不确定性。没有人工审核所有增强的语义标签，也未做受保护群体或因果图识别。
