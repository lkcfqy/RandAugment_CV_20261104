# 增强抽样粒度：本轮资格审查

2026-10-21。**本轮保留 0 个研究候选，不启动 CPU 验证。** 这是对下面一个具体命题的阶段否决，不代表增强研究结束，也不代表穷尽了全部相关工作。未继续解释 smallNORB 的横纵差值。

## 核对到的事实

[AutoAugment 原文 §3](https://arxiv.org/html/1805.09501v3) 逐图选择子策略，各操作有应用概率和幅度；原文也已讨论训练轮数需足以曝光各子策略。[RandAugment 正式论文 §4 / Fig.3](https://papers.nips.cc/paper/2020/file/d85b63ef0ccb114d0a3bb7b7d808028f-Paper.pdf) 从 14 项池均匀有放回抽 N 项，各按自身尺度使用共同 M。[TrivialAugment §3](https://arxiv.org/html/2103.10158v2) 每图抽一项操作及随机强度；TA 此处复用项目此前已读原文记录，本轮未重新获取其全文。

本机 torchvision **0.29.1** 的 v1、v2 AA/RA/TA 源码中，policy/op、强度和符号的随机抽样均在一次 forward 内作标量抽样。直接对整个图像批调用，会共享这些参数；在 Dataset 中逐图调用则会分别抽样。这是已知接口语义，可以提醒演讲听众写清抽样单位；不能据此声称作者实现错误或普通逐图加载存在问题。

静态核对仅使用源码 AST、包元数据和 SHA256，未导入或运行模型；也未证明所有 PIL/Tensor 后端逐像素等价。证据与行号见 [interface-audit.json](interface-audit.json)。

## 唯一待审命题与最近先例

待审命题：固定每张图的增强状态及曝光次数、每步原图集合、batch size、更新数和读出初始值，只重排不同图片之间的增强状态耦合；整批共享状态，是否相对逐图独立重排／Latin 排布，造成较大的梯度波动和较慢的固定预算收敛？

| 直接先例 | 已覆盖 | 本题仍不同之处 |
|---|---|---|
| [FreeAugment，ECCV 2024，§3.4 p.8](https://www.ecva.net/papers/eccv_2024/papers_ECCV/papers/03848.pdf) | 明确把逐图而非整批抽策略，与降低增强期望估计方差联系起来；上下文包含分类模型及策略的双层更新。 | 主文未见固定 TA 状态库、逐图等曝光的隔离对照；本轮未读补充或代码，不能排除更近覆盖。 |
| [Fort 等，arXiv:2105.13343v2，§2–4、附录 A/C](https://arxiv.org/html/2105.13343v2) | 分开增强噪声与原图子采样噪声；附录 C 比较同批副本和相邻批重用原图。 | 该对照每步独特原图数不同，不等于本题仅改变跨图状态耦合。 |
| [Hoffer 等，arXiv:1901.09335v1，§1.2、§2–3](https://arxiv.org/html/1901.09335) | 研究同图多增强副本、梯度相关和 batch 扩大。 | 改变副本及有效 batch；不能凭其符号记法断定实现整批共享。这里核读的是 2019 v1，未冒充 2020 定稿逐行核验。 |

**精确的等曝光实验未在这三项已读材料中检出，不能写成“它们已把相同实验做完”。** 但当前提出的正向预测仍只有已直接提出的抽样方差机制和一般随机重排后果，尚无明确的 CV 性能后果、异常观察或可预先区分的适用边界。为再画一条源训练收敛曲线建立新状态库，信息增量不足。因此暂不纳入原创候选，不执行该实验。

这不是要求必须发明新算法或新数学理论；一个有实际后果、条件清晰且未有等价实证的问题也可能值得做。本轮否决的是**目前这个只落到固定读出源目标的版本**，不是排除未来所有抽样粒度研究。

## 可反证预测、最小条件及边界

若以后出现实质新观察，最小实现可仅用已消费的源开发图、固定 eval 编码器和预先锁定的共同状态库，每臂重排同一批 (原图, 状态) 对。无需新下载或 GPU；按对象／原图保留 ID，统计随机排布重复不能充当新原图重复。用完整源状态库目标评价优化，不读旧测试来选状态、学习率或停止点。一天内可以反证，但本轮未通过启动门槛，故未实施。

预先可推翻的是“共享抽样的交叉协方差为正，并造成指定更新预算的目标差”。交叉项为零／负、差异不出现／反向，或曝光、BN、原图组成不同，都不能支持该命题。固定 θ 下方差较大本身不推出有限步收敛较慢，更不能推出测试泛化较差。

形式上，固定 B 张原图，令 z_i(s)=g_i(s)−E_s g_i(s)，则

`tr(C_shared−C_independent) = B^(-2) Σ_(i≠j) E_s〈z_i(s), z_j(s)〉`。

右侧可正可负。逐图完整状态曝光相同还意味着固定 θ 的整轮梯度和相同；单步波动不是整轮不可消除噪声的证明。训练态 BN 或跨图损失会改变前提，不能混进“只改耦合”的解释。
