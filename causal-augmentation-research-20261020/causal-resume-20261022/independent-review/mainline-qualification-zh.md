## 结果前的方案修订

初稿以统一权重 q0 对比五个标签×(方位,光照)联合关联权重 qB。独立审查指出：虽然同样540图、15物体、各物体总权重及所有预定单因素边际匹配，qB的图像权重集中度不同；Kish值为4500/11≈409.09，q0为540，不能排除普通重加权/有效正则差异。

主线在读取新数组/结果之前，加入同集中度 qS，并将主要量改为 qB与qS的增强交互；q0仅作描述参照。这是有记录的结果前设计修订，不能覆盖旧 O/V 等已完成阴性结果。独立审查没有对真实文件访问历史作完备取证，读取顺序须由执行锁与代码另行记录。

在5类×每类3物体×6方位×3仰角×2光照网格上，设 u=(-1)^(gA+gL)，gA按已锁方位rank的前三/后三分组，gL为两光照rank。均匀q0=1/540；alpha=.8；t=(-1,-.5,0,.5,1)。

qB_k(r)=[1+.8*t[(y+k) mod5]*u]/540。

qS_k(r)=[1+.8*C[(y+k) mod5,j]*u]/540，其中j严格沿既有source_objects每类顺序，不能根据特征/结果安排；

```
C = [-1,    0,    1;
     -.5,  .5,    0;
       0,   1,   -1;
      .5,  -1,   .5;
       1, -.5,  -.5]
```

方位组只能称低/高编号组，不能据此称已校准的语义正面/背面。真实拍摄含自遮挡、反射、阴影等，光照ID也不是物理剂量。

## 精确代数核验

标准库 Fraction 程序 `verify_matched_concentration.py` 已完成必要条件核验，结果为 `matched-concentration-verification.json`；它只生成索引网格，未读项目数组、图像或模型。所有以下恒等式通过：

- C各行和0、各列均为t的排列、15系数每个t恰出现3次。
- qB/qS全支持，最小1/2700、最大1/300；每配置归一化，总/类/物体权重及每物体的方位、仰角、光照边际相同。
- 无条件完整(方位,仰角,光照)联合相同；类别×方位×仰角与类别×仰角×光照联合也相同。
- qS的每类完整拍摄条件联合均匀；qB的类别×方位×光照联合发生变化。
- 每配置qB/qS全图权重直方图相同：五个权重值各108图，Kish值均4500/11；该值是权重集中度，不是独立对象数或真的丢掉131张图。
- 每物体在五配置中的系数多重集匹配；两臂各自逐图平均权重都回到q0。**必须各配置分别拟合，再平均开发风险；先混合权重拟合会抹掉处理。**

qB/qS在单一配置内的每物体权重直方图并不相同，只在五配置平均后匹配；qS仍有对象×条件关联。这是处理定义的组成部分，不能称全部干扰均已消除。

仅看metadata的u，qB可给出36%的五类Bayes正确率，而qS为20%；这说明构造的联合线索确实有标签信息，**不证明冻结图像特征能恢复u，也不证明读出真的利用它**。初稿qB的I(Y;u)约.18014nat同样只是构造属性。

## 可识别性与近邻差异

在固定源图/特征、学习器与软件实现下，可识别的是：把同类对象的联合条件关联统一对齐，与在同类内部抵消，是否改变固定weak池相对clean的已消费开发风险。随机增强核的期望被精确枚举，读出拟合也固定；无需为此假定真实世界所有物理因果图已恢复。

这里**未改变支持**，不能叫联合支持缺失。它不识别自然物理do效应、纯像素高阶shortcut机制或完整RA训练收益；像素本身的加权分布并未被证明不变。训练政策因果对比与对真实世界生成机制的因果解释应分开。

最近原文定向核对：

- [Jeon等，2025v1，§3/A.2/A.6](https://arxiv.org/html/2501.04288v1) 已在smallNORB及其他多属性资料上比较单项/并发分布变化与AA/RA。已读实验不是本方案的严格权重匹配对照；数据集、组合变化或增强能影响捷径本身都不是新意。
- [Nuisances via Negativa，2024v3，§2及C.3.2](https://arxiv.org/html/2210.01302v3) 对向量nuisance和重加权给出一般框架，并有多个有偏背景特征；它的XOR例子用来构造语义变量，不等同本题“每一单因素与Y独立、其联合有标签信息”的实证对照。
- [Whac-A-Mole，2023v2，§2.1/3/5](https://arxiv.org/html/2212.04825v2) 直接研究多捷径与增强放大其他捷径；UrbanCars中两个捷径分别与Y高相关且给定Y独立，本题隐藏于联合的关系不同。该差异支持有界测量价值，不能单凭未见完整同表就称原创贡献。

主线另已读Wiles相关章节；本独立审查不把一般向量属性理论说成不能容纳联合因素。Geiping验证入口继续停止，其精确覆盖未知；主线新报告的PMC验证入口也未重试。以上不是穷尽检索或新颖性认证。

## 一次pilot的锁定边界

主量为每开发物体先平均36视图、每配置计算(LLweak−LLclean)_qB−(LLweak−LLclean)_qS，再平均五配置，最后类别平衡平均的J*。预测/筛查门为 **J*≥+.02nat，且类别内配对对象重采样稳定区间下界>0**。五配置和全部q0/qB/qS的绝对风险及增强差值均须报告；配置不是独立重复，不能只挑一个成功类别或配置。

五配置×两权重×两政策，加q0两政策，共22个唯一头。所有策略的源独特图数540、源物体15、原图总权重、weak混合质量、λ=.01、初值、特征归一化、求解精度相同；弱池为clean1/3与五家族正负各1/15。采用收敛目标匹配，不把不同实际优化迭代数冒充不同训练预算；特征调用数和拟合耗时另报。源数据行和既有对象ordinal映射还须由运行程序验证，本网格证明不能替代真实缓存对齐。

所有22头应先冻结，再解码既定dev_seen；只读已消费10个开发物体，旧final25物体、封存数组与其他角度不使用。每类2物体只有很有限的对象精度；其区间条件于源15物体、固定表征和学习配方，不含新源物体、端到端训练或自然总体不确定性。

图像来自同一物理玩具支持类别事实，但二维增强沿用源标签不等于已独立认证可辨识性。保持既定轻度操作，不据结果删图、改幅度或把模型分数当真实标签审核。相对增强差异不能独自确定标签损坏、物理变化模拟或特定shortcut的唯一解释。

以下情形应分别记录：

1. 非有限、梯度未达预先容差、行映射/权重匹配失败、时间/内存守卫触发或未增强正控不足：技术/测量不可评价，不作科学阴性。
2. 有效运行但J*反向、量级不足或区间门未过：预设有限命题未获支持，不改指标/α/C/池或挑配置再跑。
3. 即使门通过：只获得有条件开发信号；若weak在两处理都比clean更差，不能声称已找到实际增强赢家，也不自动成为新贡献或确认结果。

原有 O/V主量−.004294nat及区间[−.009271,+.000683]、两臂weak均优于strong、主翻转失败的判断必须保留。未来确认另需未用于问题选择的新物体；不能从全部已消费50物体中恢复盲测身份。
