## 哪些只适合演讲，哪些属于已核实工程事实

| 内容 | 可以据此讲什么 | 不能据此声称什么 |
|---|---|---|
| AA / RA / TA 方法对比 | AA 搜索带概率/幅度的子策略；RA 缩小到 N/M 等选择；TA 每图单操作与随机等级。简化搜索不保证每种任务或每张增强图安全 | 三篇不同实验设置可以直接按准确率排名，或所有名义强度具有相同物理变化 |
| 已知成像/饱和反例 | 在指定合成模型中，联合变化可能合并判别线索；可解释“为什么单因素成功仍不保证联合成功” | 原创理论、真实世界因果验证，或 RA/TA 的训练优劣 |
| 因果/干预设计审计 | 类别任务、历史目标解码、世界 do 效应是不同目标；坐标/测量需一致 | 目标解码准确率就是因果效应，或像素后处理改写了历史干预目标 |
| 保守微调修复 | base / TA 已建立可复用的稳定开发配方，关键检查点和轨迹保存完整 | 已唯一定位底层根因；已分离低 LR 与 warmup 作用；已证明增强贡献 |
| 历史 Mac CPU/MPS 检查 | 本机 MPS 在当时固定训练输入及模型上有实测加速和有限数值差异 | 对所有任务的速度承诺。本轮没有再用 GPU 或重跑基准 |

## 两路独立审查为什么没有保留新命题

**实验侧：** 审读12份结果报告及协议、轨迹、核验回执。旧 base 的 LL≈0.69315 / 50% 已被联合修复覆盖；修复后 base/TA 干净训练 LL 分别约 4.67285e-5、1.04308e-7。TA 的固定训练探针确有 128→512→2048 步 LL `0.0186562→0.124622→0.00271345` 的非单调变化，但这些视图已在训练中出现，只有单条轨迹，缺少能排除普通随机优化/困难视图/置信度变化的对照。不能事后挑点命名为遗忘、double descent 或新增强机制。旧128步冻结/微调代理差异也受欠学习和失稳影响，且用了已消费开发集，不能当可靠策略排序异常。

**方法侧：** 定向阅读四项直接后续，均在本轮截止前公开。不是穷尽查新。

| 原文及实读版本 | 已覆盖的具体边界 | 为什么不据此开本轮实验 |
|---|---|---|
| [FreeAugment，v1，2024-09-07](https://arxiv.org/html/2409.04820v1) | 可变深度、重复操作、逐图/逐批策略、warmup、接续权重/重训 | 不能把去重复、频数配平或批内共享直接改名新贡献；不同 Gumbel 参数化也不是纯采样律的独立因果对照 |
| [RangeAugment，v1，2022-12-20](https://arxiv.org/html/2212.10553v1) | 幅度区间、PSNR 辅助目标、固定/课程目标、模型容量响应 | 名义 M 不等于语义难度、早期强度不合适等已有直接先例 |
| [Ctrl-A，v1，2026-03-23](https://arxiv.org/html/2603.21819v1) | 在线逐操作反馈控制及训练配方/评价设置 | 不是“有反馈就得到独立测试”。同时必须保留下一段的两套划分，不能片面指控全文泄漏 |
| [Botev 等，v1，2022-03-07](https://arxiv.org/html/2203.03304v1) | 单视图损失、平均概率/logits、预测不变性 KL，直接有 RA 实验 | 固定检查点上的分歧或 Jensen gap 不自动是新机制，也不识别训练收益 |

Ctrl-A §4.2 初始设置取 test 前1000张反馈，§4.3/Table3 又有从训练集划出1000张且与 test 不交叠的设置。两者训练样本量不同，不能把两表差全部归于泄漏。正文页眉另写 2026-08-24，而 arXiv v1 提交元数据为 2026-03-23，审查保留这个日期差异，不擅自当成新版本。没有据其一项设置作全面不当推断。
