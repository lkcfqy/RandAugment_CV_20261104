# 晨间证据质量报告

2026-10-21，UTC。范围：既有记录的独立统计与数据使用审查，追加更正，不做新实验。详细位置、原文和字段见 [数据主张审查](data-claims-review.json)、[统计审查](statistical-review.json)、[时序核对](chronology-audit.json) 与 [更正索引](correction-index.json)。项目入口为 [当前证据状态](../../CURRENT_EVIDENCE_STATUS_20261021.md)。

## 现在最强能说什么

**已经建立可复算的本机训练能力，并得到几个有范围限制的实测结果；尚未建立新的增强算法总体收益、真实世界因果效应或可确认的原创贡献。** 不能因此说数据增强无效，也不能把所有阴性结果追溯性说成测试泄漏。

| 结果 | 可主张的范围 |
|---|---|
| 保守微调修复 | base/TA 两臂各 2048 步，训练损失下降、参数有限，关键检查点已保存并经历史核验；支持这套配方能训练。训练集拟合不证明 TA 泛化更好，低学习率与 warmup 的各自作用未分离。 |
| 过滤对源权重控制 | 固定特征与读出的 LL 收益为 **−0.00589149 nat**，照片配对 95% bootstrap 区间 **[−0.01330894, +0.00007220]**。未支持预定额外收益；不证明过滤普遍无效、等效或显著有害。 |
| 区域亮度耦合 | 所报归一化背景敏感性差值 **+0.00311082**，条件区间 **[0.00151742, 0.00468280]**；相对下降 **3.532%**，未达预设 **20%** 投入门槛。它是固定模型/供体条件下的小幅差值，不能写成零效应、准确率提升或已识别语义因果机制。 |
| Equalize / 面积配对 | 指定有限处理分布上的机制筛查未通过；不能推出完整 AA/RA/TA 训练无益。Equalize 的“失败”只指沿用源标签时固定模型响应变差，未盲审认证所有变体的语义可识别性。 |
| 联合饱和检查 | 两个固定模型在 64 张旧训练图上都没有新增错误；预警 AUROC **未定义**，既未证明诊断有效，也未证明无效。指定 SCM/成像反例保留为数学或课堂示例，不能直接外推真实 CV。 |

## 数据和统计单位必须一起看

| 照片集合 | 当时与现在的角色 |
|---|---|
| 既有训练 64 张 | 多次探索后用于训练/开发；含旧 Equalize 局部留出前景的全部 16 张。不是新测试。 |
| 过滤首次测试 64 张 | 现有记录支持对当时固定问题先冻结再取得；后来与 stage 开发集 **64/64 同源 ID**。当时测试可保留，现在不能再称未触碰。 |
| 亮度首次测试 48 张 | 现有记录支持三臂冻结后取得；现在已消费。没有证据称其后来用于训练。 |

上述训练64、过滤64、亮度48的来源 ID 两两互斥；这不证明不同动物、无近重复或与 ImageNet 预训练无重合。过滤64和亮度48的区间均以**来源照片**为抽样单位，并条件于固定训练资料和模型；名义覆盖还依赖类内照片可交换/代表性的假设，SHA选样与大小限制不是已核验的总体概率抽样。亮度的 **192 个视图、4 个供体、3 个处理臂、9 份检查点**不增加独立照片或训练重复数；该亮度实验只有 **1 个训练 seed**。Equalize 多视图/宏块、256 个训练探针、8,704 个渲染帧同样不能冒充独立样本。

## 已追加的更正，而非改写历史

1. `stage-validity-pilot/pilot-results.json` 的两项 `positive` 仅为自动损失差符号；当前科学状态为**训练状态不足，无法判断代理有效性**。后来的稳定修复不使旧差值追溯性有效。
2. 饱和检查的 `weak_diagnostic_screen_supported=false` 应按**无失败事件、无法评价**读取；旧晨间稿的“条件效应不是零”收紧为**所报条件差值为正且条件区间不含零**。
3. `fresh/heldout` 只保留历史局部含义；旧候选、10月20日“未训练”快照、旧37类/A100待批提案均有明确继承/关闭映射。`completed/pass` 是交付或核验状态，不是科学主张通过。

原始文件、数值、时间和哈希不覆盖。机器汇总应先读取 `correction-index.json` 的当前状态，不应仅搜索旧 `positive/retained/pending` 字符串。

## 阈值与停止规则核验

28 项小文件 SHA256 引用一致；过滤、亮度、Equalize 的内部记录顺序均为协议/冻结在对应结果前。亮度还记录了冻结后取图；20% 门槛、过滤 0.01 nat 门槛及 Equalize 筛查与结果中的比较一致。它们是**投入筛查**，不是等效性检验或功效保证；亮度未提供相对改善率区间，准确率点值门槛也不是正式非劣效检验。早先实现修复、训练诊断和局部留出不因此变成独立确认。

内部时间和哈希不能替代第三方预注册，也不能证明未记录的分析决策不存在；归档 mtime 更晚，不当执行时钟。本项目多轮探索没有全项目同时覆盖/错误率保证，不能事后挑一项阳性再称“95%原创发现”。本轮未重跑 bootstrap、预测、训练或读取测试像素。

## 尚缺证据与最小补证路径（不执行）

- **只修正当前结论：** 已有清单、协议和汇总足够，无需新增图片或训练。
- **要主张训练算法收益：** 先锁定一个仍有增量的问题、实际目标分布和有意义差值；使用未参与选择的新来源单位、匹配预算的多次训练，分别报告照片与训练随机性。若推断到新背景，还需新供体/场景层。具体样本与重复数需按目标精度设计，不能预称“3个seed足够”。历史两臂训练约188秒仅是本机吞吐参考，不是新实验总成本承诺。
- **要主张无效或真实因果效应：** 前者需预先定义等效界及足够精度；后者需明确 estimand、干预/测量与可识别假设。增加旧图视图、seed 或换背景本身均不能补足这些条件。

当前没有等待批准的具体训练任务，也没有必要立刻申请 A100。后续只读问题核对可在现有授权内继续；一旦形成值得升级的明确问题，再决定独立数据与重复预算。本报告完成证据整理，不宣告整个项目结束。
