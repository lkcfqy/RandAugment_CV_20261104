# 类别标签保持与干预任务保持：有约束的设计审计

审计日期：2026-10-21。只读原文、官方 loader 和公开元数据；没有训练、下载数据或运行视觉/外部生成模型。研究审查使用两名已授权的内部智能体。

**审计通过的原创候选：0。** 可测的冲突是类别任务与干预任务所需信息、测量或坐标约定的冲突；像素后处理不能改写历史上干预了什么。下列两项分别保留为已知机制复现设计与排除假冲突的负控，不升级研究贡献，也不据此立即开实验。

## 1. 先定义目标，避免把不同问题混在一起

设 U 为外生变量，Z 为生成图像的状态，X=g(Z)；Y 为物体类别，I 为一次历史干预的目标索引或多热指示向量，V 为设定值。增强 O=A_Θ(X) 是记录图像之后的处理。

- Y 的注释未变，不等于增强图仍足以识别 Y；需要生成真值/语义检查与独立分类正控。
- I 的历史事实不变，但 O 可能不再足以解码 I。I 识别准确率、条件互信息等属于信息或任务指标，不能直接称为世界因果效应。
- I 不等于 V。干预的后代变量发生变化，不表示这些后代也被直接干预。
- 帧 t 与 t+1 的自然动力学会改变状态；相邻帧不是自动成立的“仅目标机制被替换、非目标外生噪声固定”的反事实配对。这样的反事实配对仍允许后代状态改变。

若研究增强本身，可定义两个随机政策 a∈{shared,independent} 对同一原始配对单位的观测 O_a，固定解码器 d，并估计：

```
theta_aug = E[ loss(d(O_independent), I) - loss(d(O_shared), I) ]
```

随机分配增强且保持单位配对、无跨单位干扰、政策实现一致，即可识别**这两个增强政策对该固定解码器损失的影响**；不需要因此假设原世界的 I 已随机化。它不是 do(Z_i=v) 对物理结果 W 的效应，也不直接证明 Bayes 信息损失。

后一个世界目标必须另外写成带单位和时间范围的查询，例如：

```
tau_j(v1,v0) = E[ W_(t+h)^(do(Z_j(t)=v1)) - W_(t+h)^(do(Z_j(t)=v0)) ]
```

需明确其他同时/后续干预政策、W 的物理单位、处理取值与支持。识别可以依靠校准测量配合充分随机化/可交换性、支持与一致性等条件，或足够已知的生成机制；校准测量单独不够。不要求为了使用“因果”一词就完整恢复真实因果图。只有目标 I 而没有相应设定值或机制，不能自动得到固定剂量查询；但若 I 确为随机分配且 W 可测，特定重置 regime 的效应仍可能可识别，不能一概说所有效应都不行。

图像后处理不改变这个原世界 tau。若直接用增强后的坐标/色值替代 W，算出来的差可能只是换了测量单位或结果定义。比较训练政策造成的 tau 估计误差，又是第三个需明确学习算法、校准和随机性的实验。

## 3. 审计项 A：共享与独立增强对目标解码的差异

**精准可推翻命题：** 在非退化物体类别 Y、已核实配对和固定目标解码器 d 下，保持每张图增强边际分布完全一致，只改变 pre/post 是否共享参数；分类风险变化处于预先固定的等效容差内，但 theta_aug>0。

这是对指定 d、数据总体和政策的经验命题，不是“共享增强普遍更好”的定理。共享参数也可能遮挡两张图的同一关键区域，独立参数可能增加可用视角，方向不能事后倒置。

若用于复现，最小协议应当是：

1. 先固定配对单位及独立 train/calibration/test 划分；按物体/场景/完整序列划分，增强副本不增加样本数。
2. 用真值在政策分配前定义类别稳定子集。对七形状序列必须检查实际 shape 值，不能用 I_shape=0 替代。Y 至少两个类别，且 I 在 Y 条件下仍有变化，避免物体类直接泄露动作/目标。
3. 固定增强操作、参数、方向和边际匹配方式。冻结 d 与类别读出后才打开检验数据；先确认未增强的目标解码有可解释的正控能力，否则无法归因增强损失。
4. 每个原始单位在共同随机数下生成两政策的观测，报告配对损失差和按单位的区间；预先固定类别等效容差、主要目标损失及最小有意义差异，不能以“分类 p>0.05”宣称等效。
5. 比较未增强、共享、独立，以及记录参数后可逆还原/坐标纠正的负控。不仅比较不同模型的探针准确率；更强的信息丢失主张需要已知有限分布、不可区分碰撞或充分 oracle。

**否决条件：** 类别读出本身明显变差、目标正控无能力、独立单位不足、边际分布未匹配，或 theta_aug 没有预定方向/幅度，都不足以支持该具体命题。原始历史元数据确实标错，会使原结论无效。但给模型提供增强参数、还原输入或把目标改成新坐标标签，会改变输入、政策或任务；差异因此消失不自动否证原固定解码器的 theta_aug，只能帮助区分坐标对齐或侧信息恢复机制。

**新意审计：否决为原创候选。** 与 Eastwood 的共享结构和 AugSelf 的信息保持原则过近。将 style 改叫“干预目标”或更换一个解码任务，不足以给出新机制或明确增量；有限的原文核对没有证明这个特定任务组合从未被实验。可以作为课堂复现，当前不训练。

**一天预算边界：** 若已有合法小配对、非退化 Y 和固定可用 d，可把冻结评估限制在单线程 CPU、千级配对和不超过半小时计算；这是未来运行上限，不是实测耗时。当前这些输入并未齐备。用小型已知生成过程和解析读出可作机制检查，但不能据此声称真实 CV 新贡献。

## 4. 审计项 B：干预坐标与元数据传播负控

**精准可推翻命题：** 若像素增强确实对应已知 latent 节点置换及逐变量可逆映射 q，正确传播目标索引、设定值、坐标系与机制后，oracle 对干预分布的描述不应仍存在纯坐标不一致；否则首先检查像素/latent 对应、非可逆处理和测量实现。这不是对原固定神经解码器损失必归零的预测。

例如 W1=-Z2、W2=Z1 的坐标重命名下，原 do(Z1=v) 需要使用相应的 W2=v 描述，而不能沿用旧坐标索引。这里改的是表示中的元数据，历史世界目标仍是 Z1。

一般混轴变换不保证保留单节点干预的形式。对

```
W1=(Z1+Z2)/sqrt(2), W2=(Z1-Z2)/sqrt(2)
```

原 do(Z1=v) 推成支持约束 W1+W2=sqrt(2)*v，并非仅将某个 Wj 固定为一个值；完整推送分布还须传播机制与噪声。因此，任意混合后的坐标差、可预测性或相关性不能被叫作目标保持率。

**识别前提：** 必须先证实 `A(g(z))=g'(q(z))` 以及合法干预映射，其中 g' 是已知的处理后观测映射；在同一渲染系统中可取 g'=g。不能对不在原渲染流形上的任意 RA/TA 结果假设存在唯一 g^(-1)。如果只对增强后的颜色/坐标重新定义结果量，测得差异不等于原世界 tau 改变。

**最小反证设计：** 只对已知生成器的节点置换/逐变量映射作穷举 oracle 检查；同时放一个非闭合混轴例作为负控。不需要神经网络或学习因果图，可在一天 CPU 上检查，若缺少准确生成/映射则根本不运行。此处未运行图像生成或程序实验。

**新意审计：否决为原创候选。** 一致传播元数据属于正确的等变性/因果重参数化要求；未传播导致的“冲突”是排错事项。它值得作为项 A 的负控，不是本项目的新方法或新原理。

以下为论文、官方 loader 或网页清单证据；**没有下载 NPZ 核验样本内容**，代码格式要求不等于已验证全部归档字段。

| 数据 | 已核实格式/标签 | 资源和门槛 |
|---|---|---|
| [CITRIS 官方数据页](https://zenodo.org/records/6637749)；[loader](https://raw.githubusercontent.com/phlippe/CITRIS/main/experiments/datasets.py) | Pong loader 读取 `images, latents, targets, keys`；Temporal Causal3DIdent 读取 `imgs, interventions, raw_latents, shape_latents` | 清单：Ball-in-Boxes 8.8 MB、Pong 52.4 MB、Teapot 561.7 MB、7-shapes 1.3 GB。未核实更小的逐样本入口/压缩包最小文件，数据许可未确认 |
| [CausalTriplet 仓库](https://github.com/CausalTriplet/causaltriplet)；[loader](https://raw.githubusercontent.com/CausalTriplet/causaltriplet/master/dataset.py) | `verb_class, noun_class`、前后图像路径、`scene`，可选框和实例 mask；真实部分另有 `participant_id, video_id, start_frame, stop_frame` | 模拟 100k 对、24 物体类、7 动作、10k 房间；真实 2632 对。README 标总量约 165 GB，公开房间0–2000子集的大小和最小文件未知。代码 Apache-2.0 不能当数据许可，数据许可未确认 |

CITRIS 的几项关键限制：

- Pong 没有本问题要求的非退化普通物体类别；背景、比分等不能悄悄替代目标 Y。Teapot 也是单一形状。不能以恒定类别的零错误证明“类别保持”。
- 七形状在同一数据集和序列中变化，可以定义 shape-class Y；但论文附录 C.1.2–C.1.3 说明它还有 5% 概率的非干预形状变化。I_shape=0 不保证 pre/post 类别一致。
- 训练仅使用 I，不等于公开文件没有 latent 值；loader 明确读取这些真值。目标后随机重置的 regime 与固定剂量 do(Zj=a) 仍不是同一个查询。
- 真实 CausalTriplet 动作对也不能自动视为随机处理或固定外生状态的反事实对。`verb_class` 不是通用 latent 节点编号；物体可供动作还可能与 noun_class 强相关。
- 本项目现有 Pets 照片没有已知世界干预 target/dose；不能通过重命名旧软件变换来补造这类真值。

因此两源均未通过当前“一天内、小数据、已确认许可、无需新生成依赖”的完整执行预检。本轮不下载 1.3 GB/165 GB、不安装生成器或模型，也不让用户收集数据来填这个缺口。

## 6. 本轮收口与证据

本轮完成了两个具体审计项的 estimand、否决条件、直接先例和资源核对；结论是 **0 项原创候选、1 项已知机制复现设计、1 项元数据负控**。不运行已经被新意审计否决的训练，也不把缺少合适数据包装成方法无效。

如后续再找该方向的原创问题，必须先提出超出“任务信息不同”与“坐标需校正”的精确预测，明确何种数据能推翻它。当前不能以更多探针/随机小实验代替这个缺口。此收口仅针对这一轮设计，不宣布增强研究整体结束。

两名独立审查者分别核对数学/识别和原文/数据；来源边界、访问失败和模型请求证据在同目录 JSON 中保存。明确请求 GPT-6.1-Sol/max，但接口无实际执行档位回执。没有训练、调用外部模型、MPS/A100、ARIS、自动化、PPT 或 8A 文件操作，旧关闭记录全部保留。
