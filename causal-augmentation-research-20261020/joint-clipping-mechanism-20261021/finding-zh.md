# 联合增益何时合并判别线索：一项受控机制检查

结论：保留一个具体候选——**单因素验证均保留判别线索，但联合新增饱和把该线索合并，因而漏判不同读出的相对风险**。本轮给出了明确阈值、可观测预测式和辨识反例；只完成受控合成的精确检查，没有训练 AA/RA/TA，没有真实世界因果验证，也没有证实原创贡献。候选不必以提出更好的选择算法为前提。

## 1. 问题和适用目标

目标环境是同一物体同时受到曝光增益和逐通道增益变化。询问的是：在单因素验证中占优的模型，是否因为使用了会在联合环境中消失的判别线索而失去优势？“联合变化更难”或单纯排序反转不构成新意；待检验的具体解释是**判别对比跨过了联合截断阈值**。

逐通道乘法只是明确的成像近似，并不等于任意真实光源变化。这里固定对象标签，比较变换后图像上的预测风险，不再使用此前不适合视觉分类目标的 `do(image)` 因果风险。也不把替换背景等同真实干预。因果视角在本轮是对可控成像因素及其交互的分析，不要求恢复完整真实因果图。

## 2. 可识别性及边界

假设：像素配准、无噪声、已扣黑电平、共同白阈值归一化为 1、固定线性响应、因素可分离，且曝光增益 e 与通道增益 c 均不小于 1。对单个通道的 x∈[0,1]：

```
I00 = x
I10 = clip(e*x, 0, 1)
I01 = clip(c*x, 0, 1)
I11 = clip(e*c*x, 0, 1)
I11 = clip(I10*I01/I00, 0, 1)  (I00>0；零输入按零处理)
```

两张 single 都未截断时，最后一式直接由乘法成立。若任一 single 已到白阈值，另一 single 至少为 x，乘除结果至少为 1，联合图也必到白阈值，所以预测仍成立；无法恢复的是阈值以上的幅度。纯幂编码 g(x)=x^γ（相同 γ>0、共同归一化白阈值）也保持这一关系，不能笼统说“未知 gamma 就失效”。

**联合才到白阈值的像素集合**为：

```
J = {1/(e*c) <= x < 1/max(e,c)}
```

若指严格超过阈值造成截断，左端改为开区间。本轮对 e=c=1.4，有 J=[25/49, 5/7)。该公式和增益物理不是本项目的新贡献。

两项操作即便每步都 clip，在非减增益条件下仍可交换：`clip(e*clip(c*x)) = clip(c*clip(e*x))`。所以本例不依赖操作顺序。

## 3. 预先固定的分类反例与实际结果

用两个合成 RGB 色块构成图像。类别 Y∈{-1,+1} 等概率；红通道的 0.65/0.55 左右顺序完全决定 Y。蓝通道的 0.10/0.02 顺序为 S=Y*N，其中 N 以 0.1 概率为 -1。每个单位的 N 在四个环境中固定，其他通道仍保留图像差异。

固定两个读出：h_color 读红色块顺序（平局预测 +1），h_blue 读蓝色块顺序。曝光乘所有通道，另一因素只把红通道乘 1.4。枚举全部四个 (Y,N) 支持状态及其精确概率，结果是**总体期望的精确值，不是 n=4 的准确率估计**：

| 环境 | h_color 错误风险 | h_blue 错误风险 |
|---|---:|---:|
| 原环境 | 0 | 0.1 |
| 仅曝光增益 1.4 | 0 | 0.1 |
| 仅红通道增益 1.4 | 0 | 0.1 |
| 两项同时 1.4 | 0.5 | 0.1 |

单因素下红值为 0.91/0.77；联合未截断值为 1.274/1.078，截断后均为 1。按原环境及两个 single 选择 h_color 时，联合环境相对 h_blue 的后悔值为 0.4。蓝空间线索仍在，图像并未全局擦除。

令联合乘积 k=e*c，红判别幅度满足：

```
Δ(k) = k*(0.65-0.55)    k <= 1/0.65
       1-k*0.55         1/0.65 < k < 1/0.55
       0                k >= 1/0.55
```

这给出了“何时发生”：**较亮色块先饱和尚不足以翻转，两个判别色块都到白阈值才使此固定读出失效**。相同图像的 h_blue 不受影响，也说明饱和计数自身不足以预测任意模型风险。

两个预定对照均消除反转：①把两项增益都降为 1.2；②在数学成像模型中不作截断。第二项不表示可以从已截断照片恢复信息。交换操作顺序结果不变。本轮没有根据结果选择增益或读出。

实际执行：首轮即通过；3,636 个精确有理数格点验证乘除预测、交换律及联合阈值；另有 7,272 个纯幂响应格点（γ=2、3）。Python 标准库 CPU 用时约 **0.0643 秒**，峰值 RSS 见 `results.json`。未训练、下载图片、访问最终留出或使用 GPU。

## 4. 未知相机响应的最小反证

即使 e=c=1.4 已知，原图和两张 single 中**一个像素/通道的三元观测**也不足以识别任意未知固定单调响应下的联合值：

- 世界 A：线性响应，原信号 0.55，观测原图/两 single 为 0.55/0.77/0.77，联合结果为 1，发生饱和。
- 世界 B：原信号 0.30；固定严格递增的分段线性响应依次通过 `(0,0)、(.30,.55)、(.42,.77)、(.588,.90)、(1,1)`。观测三图仍为 0.55/0.77/0.77，联合原信号 0.588 未饱和，观测联合图为 0.90。

两个世界对这三个标量观测完全一致，对联合值和是否饱和给出不同答案。没有验证世界 B 的响应同时拟合第 3 节整幅 RGB 反例；若整图提供额外校准信息，需要重新分析可识别性。因此，在未知非齐次响应下连这个像素机制都可能不可识别，更不能从任意 JPEG 的饱和率推断真实模型的因果失效。真实噪声、配准误差、自适应 ISP 和光谱交互还需要单独验证，当前没有被本反例覆盖。

## 6. 候选的地位与下一项反证

**保留为待实证的具体机制候选，不宣布贡献，也不因没有新算法而否定。** 本轮超过“联合失配已知”的部分是明确的线索合并阈值、对应的预测式以及何时无法辨识；但这些代数本身很初等，合成正例不能使它变成真实 CV 发现。

真正的增量需回答：固定 AA/RA/TA 训练得到的模型之间，是否确有不同的判别线索依赖，使 single 验证失误集中出现在可预测的 joint-only 截断边界，而非一般强度增加？RA 的 Brightness/Color 等实现不等于本模型的 RAW 曝光/对角增益，不能直接替换概念。

下一项有信息的检验须有配准、处理条件清楚、标签可得的真实交叉变化数据；先用不参与选政策的单位验证联合预测和成像假设，失败则放下该外推。成功后才在独立单位上锁定政策、阈值和主要指标，比较 single 选择与 joint 风险；需用只饱和非判别区域、降低增益避免饱和、相同范围的高光保留等对照区分总变化强度与线索丢失。若没有政策排序/风险效应，或效应不随该阈值及对照变化，机制解释被削弱或推翻。当前没有取得满足这些条件的真实交叉数据，本轮也未重试 ALOT 等受阻入口。

两名独立审查智能体分别核对数学/实现和六项最近原文范围，见 `review-record.json`。工具可证明曾请求 GPT-6.1-Sol/max，但不能返回每次实际运行的模型/推理档位，因此不声称实际档位已核验。旧结果、课堂材料及 8A 文件均未修改；未使用 ARIS、GPU、调度或新依赖。
