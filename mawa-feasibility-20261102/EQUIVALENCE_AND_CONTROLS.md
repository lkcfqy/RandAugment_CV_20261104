以下是本次静态核查的数学与实现说明。没有真实特征训练，也不构成启动后续实验的许可。

令 (c_i=F(x_i)\in\mathbb R^d\)，(z_{ik}=F(t_k(x_i))\)。所有目标均为对应 clean 特征 c_i。定义 (M_0=\frac1{Nd}\sum_i\|E(c_i)-c_i\|^2\)，(M_a=\frac1{Nsd}\sum_{i,k}\|E(z_{ik})-c_i\|^2\)。论文的逐视图等权目标除以 d 是 ((M_0+sM_a)/(s+1)\)；发布版是 (λ(0.5M_0+1.5M_a)\)。s=1 时比例不同，s=3 修正目标复制后才相差常数 (2λ\)。改这个比例是在改科学目标，不能称优化器配平。

**相似坐标变换**


\[
T(u)=au+b,\quad a>0,\qquad E^T_\theta(u)=T(E_\theta(T^{-1}(u))).
\]

有 (E^T_\theta(T(z))-T(c)=a(E_\theta(z)-c)\)。所以 (L_T(\theta)=a^2L(\theta)\)，每个样本权重固定时都成立。目标和输入必须一起变换；只归一化输入或只缩放输出不是这个等价关系。对原始及刚性对齐后的欧氏近邻，若 cloud 和匹配规则一起正确变换，身份保持；不适用于“平移后再算余弦相似度”。

推荐的唯一严格配平是保留相同的参数变量 θ、初始值和优化器状态，使用 wrapper，同时优化 (L_T/a^2\)。此时数据损失梯度逐项相同，原参数上的 weight decay、学习率曲线和 clipping 均无需变化。这也是合成梯度测试采用的方式。

若坚持保留 (cL\)、c=a²，在**相同参数化**下：

- 无正则 SGD：学习率改为 η/c；有 momentum 时缓冲量也对应乘 c。若采用梯度裁剪，阈值也须乘 c。包含正则时必须一并推导，不能只缩学习率。
- Adam/AdamW：一阶矩乘 c、二阶矩乘 c²、epsilon 乘 c，学习率不变，可使数据更新相同；AdamW 在原参数上保留相同 η 和解耦 decay。零状态初始化自动满足矩状态的比例关系。直接以原 epsilon 运行只近似尺度不变，不能声称严格等价。[官方更新式](https://docs.pytorch.org/docs/2.15/generated/torch.optim.AdamW.html)
- 以上不是“对任意原生 MLP 换坐标后调一个 LR 就够了”。它仅处理 wrapper 中剩下的常数倍损失。

对列向量 MLP (E(z)=W_2σ(W_1z+b_1)+b_2\)，无归一化或输出限制时，显式共轭参数为

\[
W'_1=W_1/a,\quad b'_1=b_1-W_1b/a,\quad W'_2=aW_2,\quad b'_2=ab_2+b.
\]

这保持了同一初始函数关系，却不保证在变换后的原生参数上直接用各向同性 AdamW 得到同一轨迹：参数映射混合了权重和偏置，weight decay 的先验也不再相同。wrapper 可避免此混淆。测试使用行向量记法的等价公式，未实例化或训练 adapter。

中心化设计矩阵 (Z_c=Z-\bar Z\) 满足 ((aZ+b)_c^T(aZ+b)_c=a^2Z_c^TZ_c\)，因此非零谱的条件数不变。未中心化的带截距设计可能改变数值条件，但该现象并不是改变特征碰撞身份的新机制。

**闭式对照与真正冲突**

将训练输入行拼为 clean 与 augmented，目标按相同 view-major 次序重复 clean。用该损失的固定权重组成对角矩阵 D，带截距的设计为 $\tilde Z=[Z,\mathbf1]$：

\[
B_\star=(D^{1/2}\tilde Z)^+D^{1/2}Y.
\]

用 QR/SVD 求带权最小二乘，不通过训练迭代或验证集选 λ。秩不足必须报告 rank 和零空间；不能把欠定插值当作机制恢复。仿射函数类在共同平移／缩放下闭合；唯一最小解时，映射回原坐标的预测与残差相同。秩不足时最小范数解的函数外推未必坐标不变，需要固定同一参数代表或只比较已确定的拟合预测。Ridge 和 bias 正则若未相应变换，会改变问题，因此不属于“同目标闭式对照”。

对**完全相同的输入特征** z、不同目标 (y_1,y_2\)，权重 w₁,w₂>0，任何确定性函数的加权平方残差至少为

\[
\frac{w_1w_2}{w_1+w_2}\|y_1-y_2\|^2.
\]

组内加权目标方差给出更多重复输入的一般式；合并多个 pair 不能重复计算同一损失项。近邻“异类更近”没有这样的无条件界。若**事先**限制函数为 K-Lipschitz，才可使用

\[
\frac{w_1w_2}{w_1+w_2}\max\{0,\|y_1-y_2\|-K\|z_1-z_2\|\}^2.
\]

未规定或控制 K，有限样本中彼此不同的输入可以由更陡的函数分开。有限点的拟合可行也不意味着对总体或未见增强可行；总体平方回归的不可约误差关联条件目标方差，而不是一个近邻错误率。这里均为既有回归事实，不是新的理论贡献。

**如未来另行重开，最低可执行对照**

1. 先取得并固定同一官方 ResNet50 V1 的 2048 维 clean/aug 对、类别、原图 ID、增强参数、预处理与哈希；没有这些不能替换成 SigLIP 或 DeiT 冒充本问题。原图身份划分 2000 train / 500 held-out，只作开发性机制数据；不得按 collision、难度、效果选图。
2. 一次固定一个目标：若忠于当前可运行发布路径，单视图 (0.5M_0+1.5M_a\)；若忠于 Eq.21，则另行声明为不同目标，不能比较时暗改比例。每个原图的增强固定一次，只研究有限配对缓存，不能声称覆盖论文的动态增强分布。
3. 仿射闭式解与标准 MLP 用相同权重和样本。共同平移 b 只来自 train mean，正缩放可固定 a=2；共轭 wrapper 与归一化损失只做等价性控制，不算新方法。同一 θ、batch 顺序、U、optimizer、LR/decay、最后 checkpoint；不调参数选择好结果。
4. 主观察是分别报告 clean 残差、aug-to-clean 残差、held-out 残差及既有结构指标。碰撞事件按论文严格距离比较，tie 不算跨类更近；不用固定旧分类头的坐标失配充当证据。
5. 可证伪点：先用 train clean 的平均中心化特征方差归一化各项 MSE，若它为零则数据资格失败；固定 δ=1e−6 作为数值容差，不作为统计显著性阈值。若 MLP 的归一化训练目标高于闭式解超过 δ，闭式解的 held-out clean 误差不高于 MLP+δ 且 aug 误差低于 MLP−δ，再结合完整结构指标，可以把“这个具体失败至少包含可避免的优化差距”列为后续待复核解释。该标准只辨别数值可行性，不自动证明实用收益。相反，闭式残差高不证明更大非线性类无解；缺少稳定性限制或明确重复目标冲突时保留未知。只出现非配平尺度敏感性即关闭，不能据此升级为方法论文。

当前没有真实 ResNet50 配对缓存或待解释的匹配训练失败，以上仅记录需要的证据，不启动该计划。共同坐标变换的等价性已经通过纯合成损失、梯度和更新代数测试，无需为确认该恒等式运行真实模型。
