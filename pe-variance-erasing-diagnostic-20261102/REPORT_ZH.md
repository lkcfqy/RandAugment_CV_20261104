**统计口径和主要结果**

输入 (V_I) 是每张归一化图像全部 C×H×W 元素的总体方差，ddof=0；token (V_X) 是真实 patch 投影全部 N×D 元素的总体方差，保留投影 bias、排除 CLS。实际 LayerNorm 另外按每个 token 的 D 维统计。位置编码敏感度 (S) 是在 α=1 时 (d\,LN(X+αP)/dα) 的 RMS，包含真实 gamma 和 epsilon；主口径为全部 patch tokens。CLS 只在完整模型输出路径保留。

**论文与实现边界**

[预印本 §2.1 与 Properties of Variance](https://arxiv.org/html/2405.14115v1#S2.SS1) 使用扁平张量方差，并把输入与线性 patch 投影方差保持联系起来。[§2.4](https://arxiv.org/html/2405.14115v1#S2.SS4) 描述 pixel 独立高斯和共享常量的 rand。已知的线性协方差关系本身没有新颖性。

[官方 timm 实现](https://github.com/huggingface/pytorch-image-models/blob/v1.0.22/timm/data/random_erasing.py) 的 rand 实际是**每通道一个常量**；通道内空间方差为 0，不表示扁平 RGB 方差为 0，本次后者中位数为 0.52106。执行的安装版源码 SHA 及副本已保存，未使用论文的单个全通道标量替换官方行为。

图像来自 PairTally，不是 ImageNet。ImageNet 均值标准差归一化没有把这些单图强制变成方差 1：无擦除输入方差范围 0.07608–1.53043，中位数 0.53894；pixel 后中位数 0.72365。因此普通模式结果不能作为论文“正确数据集统计归一化”条件下的直接复现。DINOv2 使用其既有官方实现将位置编码插值到 224，所有条件一致；未混用不同分辨率结果。样本中可能有相关图对，未做独立样本显著性主张。
