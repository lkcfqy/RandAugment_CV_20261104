MILL proxy v1 — implementation freeze specification

This is an implementation-only deliverable. Real-data fit, real synthesis, task utility, GPU use, full-resolution preflight and formal inference have not been run. The upstream mathematical delegation and its C_anchor clarification are authoritative. Neither a resource failure nor a validation failure is a scientific negative.

1. The original 84-image panel is unchanged: train Scene7, Scene16, Scene10_b, Scene12, Scene23_b, Scene15; test Test13–Test20; source X=L10, targets Y=L1/L3/L5/L7, independent bright GT G. Four seeds are 11/22/33/44. Native RGB uint8/255, q=1/255, N=240000, width=600,height=400. No linearization, ICC, alignment, crop, resize, ImageNet normalization or content-based selection. All fitting/FFT arithmetic is CPU float64; task-model inputs are FP32. Q8(t)=floor(255*clip(t,0,1)+0.5)/255. Fitting APIs accept only six train X,Y. Synthesis APIs accept only test X, frozen parameters and RNG. Test Y and GT are exposed only after generation has been frozen, in final evaluation.

2. A has one shared gamma and three gains per light level. Gamma_j=exp(log(.2)+j/4096*log25), j=0..4096, with gamma_2048 explicitly 1. Gains a_c=clip(sum X_c^gamma Y_c / sum X_c^(2gamma),0,2), zero denominator=>0. Minimize all 18N equal-pixel squared errors without clipping m=a X^gamma. Losses within minimum+1e-14 tie; prefer smallest |log gamma|, then gamma. Implementation uses exact 256-code sufficient statistics for the same objective. For each channel form t=clip(m,0,1), e=Y-m, bins min(15,floor16t), and nonempty n,mean(t),mean(e),v=mean((e-mean(e))²), ddof0. Fit beta0,beta1>=0 to sum n(v-beta0-beta1*mean(t))²; choose the minimum-L2 minimizer when nonunique. A synthesis is Q8(m+sqrt(beta0+beta1*t)*iid Gaussian). No variance floor and no residual-mean addback.

3. B per-level/channel mean curve is a 256-node weighted PAV isotonic LUT on observed uint8 input codes, constrained to [0,1]. Empty internal nodes interpolate linearly; ends use nearest; a single observed node gives a constant LUT. General query interpolation is linear; original inputs land on nodes. No additional smoothing. Source h=.2126R+.7152G+.0722B in the encoded domain; source bins min(15,floor16h), left-closed/right-open with 1 in bin15. For original uint8 codes, implementation computes the mathematically equivalent integer expression min(15,16*(2126Rcode+7152Gcode+722Bcode)//2550000), avoiding floating movement of exact bin boundaries. This is only bin indexing, not a radiometric transformation.

4. B residual e=Y-g(X). Pool pixels, not per-scene weights, for each level/bin/channel: mu=mean(e), v=mean((e-mu)²), sigma=sqrt(max(v,q²/12)), mB=g(X)+mu_bin, z=(e-mu_bin)/sigma_bin. The floor stabilizes division only; z is not forced to unit variance, and constant empirical residuals give a zero-point mass. Save the entire sorted train z sample; Q(u)=order statistic ceil(n*u), 1-based, with no tail clipping or interpolation. Empty train bins copy mu,v,sigma,Q from nearest originally nonempty bin, lower-bin tie; never cascade through a newly filled bin. Record test fallback-pixel fraction. Empty test bins contribute zero and are skipped.

5. B training spectrum: subtract each train image/channel's spatial mean from z; FFT2(norm='ortho'), full two-sided; S(f)=sum_s Z_s(f) Z_s(f)^H / 6, DC=0, no smoothing. Hermitianize S and take its principal square root. Clip only numerical negative eigenvalues; lambda_min < -1e-10*max(traceS,1e-12) is validation failure, not a ridge opportunity. Preserve conjugate symmetry of real fields. The root is cached once per level.

6. RNG text is exactly UTF8 `MILL-proxy-v1|method=B|scene=<ID>|level=<1/3/5/7>|seed=<11/22/33/44>|purpose=gaussian`, no spaces or zero padding. SHA256 first16 bytes, big-endian integer, seed np.Generator(PCG64). A substitutes method=A. Gaussian array is float64, C-order [3,400,600]. B V0=L FFT(eta), DC0, fixed for that draw; u0=IFFT(V0). No donor/crop/stitch. For ten iterations: W=FFT(current u), a=V0^H W, P=0 if ||V0||=0, P=V0 if a=0, otherwise P=V0*a/|a|. Compute the smaller flat index of each (i,j),(-i modH,-j modW) pair and assign its conjugate partner. Only (0,0),(0,300),(200,0),(200,300) are self-conjugate; DC0, other self frequencies use sign of the real inner product, zero=>+1. Never force entire Nyquist rows/columns real. IFFT imaginary max must be <=1e-10*max(1,real maxabs), otherwise fail.

7. Each iteration ends with rank mapping independently for each query source bin/channel. Sort u with a fixed full-image random-permutation priority for ties; priorities have purpose ties-R/G/B, each generated once per draw and reused for ten iterations. At query rank j=1..n assign train Q((j-.5)/n). Integer-rational indexing implements the exact ceil order statistic. Iteration10 ends with rank mapping: no final spectrum projection, centering, early stop or best-iteration selection. Final synthetic image is Q8(mB+sigma_bin*u10). A single V0 is rank-one at each frequency; only its expectation has covariance S. Final diagnostic acceptance, not an exact-training-spectrum claim, determines statistical fidelity.

8. Task model: official commit eb43d7d91e9a336c66856824ff9e4603ae41f408, four original source SHA256 values pinned in model.py, MIT preserved in asset vendor tree. Safetensors hash 2291407125e809cc9c0614cc2d010d21d309a66eb3da33e1ee2386a68fa05894, 191 keys, channels [36,36,72,144], heads [1,2,4,8], norm=False. Strict state loading, exact dtype/shape and finite validation, no prefix remapping, unsafe pickle, torch.load, remote code, allowlist or install script. Explicit trans.gated=True, gated2=True, alpha_s=1, alpha=1 (the alpha_i CLI maps to alpha), external gamma=1. Preserve learned density_k. Batch1, FP32, eval, inference_mode, native 600x400, no resize/padding. Inference receives no GT. Clamp floating output [0,1] before metrics; never save/reload outputs as PNG. All GT mean correction is absent.

9. PSNR Q=-10log10(mean over all RGB pixels (P-G)²), no crop, channel-PSNR averaging, epsilon or score rounding. Zero MSE or nonfinite is validation failure. DeltaE76: per-pixel Euclidean distance in CIELAB then image mean; standard sRGB branch <=.04045 /12.92, else ((c+.055)/1.055)^2.4; XYZ rows [.4124564,.3575761,.1804375], [.2126729,.7151522,.0721750], [.0193339,.1191920,.9503041]; D65 [.95047,1,1.08883]; Lab delta=6/29. For PSNR Dreal=T_test-R_test and Dsyn=T_test-mean_draw(S); color deterioration is R_test-T_test and mean_draw(S)-T_test. Compute each draw's metric first, then average scalar metrics, never images or outputs.

10. C_meanD is the per-level mean real response over six training scenes. C_anchor_PSNR=T_test-mean_train Q(F(Y_l),G_train); color=mean_train E(F(Y_l),G_train)-E(F(X_test),G_test). These controls require no extra forward. D and C_anchor use test GT scoring and are diagnostics, not GT-free deployment predictors. Report B and C_anchor on the same complete cells and same eligible pairs, also on exactly the B-stat-pass endpoint subset. Absolute R vs mean_draw S sorting is separate: its eligible pairs use |R_s-R_t|>=.5 dB, not D differences. It is descriptive and does not enter continue.

11. Final statistical diagnostics use only final Q8 images, for both A and B relative to the same frozen B mean and sigma: r=W-mB(X), U=r/sigma. 32 separate scene×level cells. Source-bin weights n_b/N, empty weights0, single-pixel variance0, ddof0. Emean=max_channel sum_bin w mean_draw |mu_syn-mu_real| <=2q. Evar=max_channel sum_bin w mean_draw |var_syn-var_real|/max(var_real,q²) <=.15. EKS=max_channel mean_draw empirical two-sample KS(full-image U_syn,U_real) <=.05. Do not pool draws or attach independent-pixel p-values.

12. Spectrum diagnostics center each U channel spatially and FFT full two-sided ortho, omit DC. Per axis, 16 bins [-.5+i/16,-.5+(i+1)/16), final includes numeric upper; 256 rectangular bands, no window/radial bins/crop. P_band=sum |FFT|², normalize by each channel's total nonDC power. EPSD=max_channel mean_draw sum_band |Ptilde_syn-Ptilde_real| <=.15. Ecor=mean_draw max_three_pairs |Pearson_syn-Pearson_real|. Band cross S_ac=sum U_a*conj(U_c), K=S_ac/sqrt(P_a P_c); real weight sqrt(Pa_real Pc_real)/sum_band sqrt(Pa_real Pc_real). Ecoh=max_pair mean_draw sum_band realweight*|complex(Ksyn-Kreal)|. Ecross=max(Ecor,Ecoh)<=.05. Real zero-power band weight0; positive real weight and synthetic coherence denominator<=1e-12 gives error2. A real channel centered variance<=1e-12 or any real pair weight denominator<=1e-12*N gives STAT_UNIDENTIFIABLE. Nondegenerate-real / degenerate-synthetic PSD or Pearson gets error2. B cell P=1 requires all five gates and identifiability; never replace cell gates with pooled averages.

13. Response MAE uses all32 equal-weight cells (equivalently four equal levels/eight equal scenes); color same. Relative ranking uses within-level, distinct test scenes with |Dreal_s-Dreal_t|>=.5dB; |pred_s-pred_t|<=1e-8 is tie .5, correct1/reversed0. A level is sufficient iff >=8 of28 pairs covering >=6 scenes. Overall agreement averages four level agreements equally and does not round. Missing ID/scene/method/draw, nonfinite metric or validation/resource failure rejects go, never becomes scientific negative.
